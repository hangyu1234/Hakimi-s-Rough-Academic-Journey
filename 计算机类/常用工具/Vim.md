## 一、什么是 Vim
Vim 是一个功能强大的文本编辑器，我们可以在其中写我们想要写的任何内容，我们常用的**IDE(集成开发环境)**有一个类型就是基于Vim的。IDE 分为两种类型：
1. **图形化 IDE**：典型例子就是非常好用的 VScode。
2. **基于终端的 IDE**：这里就要用到我们的 Vim 文本编译器了
   
## 二、Vim 核心特征：模态化
Vim 是有五个模式的：
1. **Normal Mode (默认模式)**：
   这个模式是刚进入 Vim 时的模式，我们可以分别使用下面的按键来进入对应的模式：
   - `i`：进入**插入模式（Insert Mode）**
   - `R`：进入**替换模式（Replace Mode）**
   - `v`：进入**可视化模式（Visual Mode）**，这里是**默认版**
   - `V`：进入**可视化模式（Visual Mode）**，这里是**行可视**
   - `Ctrl + V`：进入**可视化模式（Visual Mode）**，这里是**块可视**
   - `:`：进入**命令模式（Command Mode）**

2. **Insert Mode（插入模式）**：
   这个模式是用来进行**编写文本**的，进入后就可以像普通的编译器一样编辑文本
3. **Visual Mode（可视化模式）**：
   这个模式**用于选择文本块**。上方介绍的 `v`, `V`, `Ctrl + v` 分别代表了他的三个模式：**选择文本、选择行、选择文本块**
4. **Command Mode**:
   这个模式**用于执行保存、退出等宏观指令**，使用 `:` 进入

## 三、Vim 的移动方式
Vim 的移动方式和图形化 IDE 的方式是一样的。有两种方式：
1. 使用**方向键**：上、下、左、右
2. 使用**H J K L**：H->左，J->下，K->上，L->右

还有一些其他的快捷移动方式：
- `w`: 向后移动一个单词
- `b`：向前移动一个单词
- `0`：移动到行首
- `G`：移动到文本末尾
- `:XXX`: 移动到 XXX 行
- `%`: 指向括号的时候，使用 % 来转换到前/后括号
- `f`: 按下后，再次按键就是寻找你的目标字符，在你的光标后直到行末
- `t`：按下后，再次按键会跳转到输入的字符的前一个位置
- `/`: 用于查找，输入文本后就会找到对应的文本
- `$`: 转到行末
- `H`: 转到屏幕顶端
- `M`: 转到屏幕中央
- `L`: 转到屏幕底端

## 四、Vim 的保存方式
Vim 的保存是在 command mode 中进行的，常用的有下面几种：
- `w`：保存
- `q`: 退出
- `wq`：保存并退出
- `q!`：强制退出（不保存）
