## 第一章：导论<a id = "第一章"></a>
### 1. 强化学习
强化学习就是学习“做什么（即如何把当前的情境映射为动作）才能使数值化的收益信号最大化”<br>
两个特征：试错和延迟收益<br>
强化学习既表示一类问题，又是一类解决这种问题的办法，同时还是一个研究此问题及其解决方法的领域<br>
强化学习的基本思想就是在智能体为了实现目标而不断与环境产生交互过程中，抓住智能体所面对的真实问题的主要方面<br>
具备学习能力的智能体必须能够在某种程度上感知环境的状态，然后采取动作并影响环境状态，智能体必须同时拥有和环境状态相关的一个或多个明确的目标
强化学习与有监督学习、无监督学习的不同：
- 有监督学习：从外部监督者提供的带标注的训练集中进行学习，每一个样本都是关于情境和标注的描述，采用这种学习方式是为了让系统能够具备推断或泛化能力，能够响应不同的情境并作出正确的动作，哪怕这个情境并没有在训练集合中出现过
    - 这是一种重要的学习方式，但是并不适用于从交互中学习这类问题
    - 在交互问题中，我们不可能获得在所有情境下及正确又有代表性的动作示例，在一个未知领域，若想做到最好（收益最大），智能体必须要能够从自身的经验中学习
- 无监督学习：无监督学习是一个典型的寻找未标注数据中隐含结构的过程

标注：即针对当前情境，系统应该做出的正确动作，也可将其看作对当前情境进行分类的所属类别标签<br>
强化学习带来了一个独有的挑战——“试探”与“开发”之间的折中权衡，为了获得大量的收益，强化学习智能体一定会更喜欢那些在过去为它有效产生过收益的动作，但为了发现这些动作，往往需要尝试从未选择过的动作，智能体必须开发已有的经验来获取收益，同时也要进行试探，使得未来可以获得更好的动作选择空间<br>
强化学习的另一个关键特征是它明确的考虑了目标导向的智能体与不确定的环境交互这整个问题，从一个完整的、交互式的、目标导向的智能体出发<br>
完整的、交互式的、目标导向的智能体并不一定是完整的有机体或机器人，它们也可以是一个更大的动作系统的组成部分

### 3. 强化学习要素
强化学习有四个核心要素：
- 策略：定义了学习智能体在特定时间的行为方式，是环境状态到动作的映射，策略本身是可以决定行为的，是强化学习的核心，一般来说策略可能是环境所在状态和智能体所采取动作的随机函数
- 收益信号：定义了强化学习问题中的目标，每一步中环境向强化学习智能体发送一个称为收益的标量数值，智能体的唯一目标是最大化长期总收益，收益信号是改变策略的重要基础，如果策略选择的动作导致了低收益，那么可能改变策略，从而在未来的这种情况下选择一些其他的动作，一般来说收益信号可能是环境状态在此基础上所采取的动作的随机函数
- 价值函数：表示了从长远来看什么是好的，一个状态的价值是一个智能体从这个状态开始，对将来累积总收益的期望，尽管收益决定了环境状态直接、即时、内在的吸引力，但价值表示了接下来所有可能状态的长期期望
- 对环境建立的模型：这是一种对环境的反应模式的模拟，它允许对外部环境的行为进行推断，环境模型会被用于做规划，使用环境模型和规划来解决强化学习问题的方法被称为有模型的方法，而简单的无模型的方法则是直接的试错，这与有目标的进行规划恰好相反

从某种意义来说，收益更加重要，而作为收益预测的价值次之，没有收益就没有价值，而评估价值的唯一目的就是获得更多的收益，然后在制定和评估策略时，我们最关心的是价值<br>
动作选择是基于对价值的判断做出的，我们寻求能带来的最高价值而不是最高收益状态的动作，因为这些动作从长远来看会为我们带来最大的累积收益<br>
确定价值比确定收益难得多，收益基本上是环境直接给予的，但是价值必须综合评估，并根据智能体在整个过程观察到的收益序列重新估计，价值评估算法才是几乎所有强化学习算法中最重要的组成部分

## 第二章：多臂赌博机<a id = "第二章"></a>
- 评估性反馈：依赖于当前采取的动作，即采取不同的动作会得到不同的反馈
- 指导性反馈：不依赖于当前采取的动作，即采取不同的动作也会得到相同的反馈
### 1. 一个k臂赌博机问题
问题：你要重复的在k个选项或动作中进行选择，每次做出选择之后你都会得到一定数值的收益，收益由你选择的动作决定的平稳概率分布产生，你的目标是在一段时间内最大化总收益的期望
- 价值：k个动作中的每一个在被选择时都有一个期望或者平均收益
- $A_t$：在时刻t选择的动作
- $R_t$：对应的收益
- $q_*(a)$：任意动作a对应的价值，是给定动作a时收益的期望
$$q_*(a) = \mathbb{E}[R_t|A_t = a]$$
如果你知道每个动作的价值，则解决k臂赌博机问题就很简单：每次都选择价值最高的动作，我们假设你不确切的知道动作的价值，但是你可以进行估计，我们将对动作a在时刻t时的价值的估计记作$Q_t(a)$，我们希望它接近$q_*(a)$<br>
- 贪心动作：在任意时刻都至少有一个动作的估计价值是最高的，这些对应最高估计价值的动作
- 开发当前你所知道的关于动作价值的知识：从这些动作中选择
- 试探：选择非贪心的动作，改善对非贪心动作价值的估计

开发对于当前最大化当前这一时刻的期望收益是正确的做法，但是“试探”从长远来看可能会带来整体收益的最大化
### 2. 动作——价值方法
动作价值的真实值是选择这个动作时的期望收益，一种自然的方式就是通过计算实际收益的平均值来估计动作的价值
$$Q_t(a) = \frac{t时刻前通过执行动作a得到的收益总和}{t时刻前执行动作a的次数} = \frac{\sum_{i = 1}^{t-1} R_i \cdot \mathbb{1}_{A_i = a}}{\sum_{i = 1}^{t - 1} \mathbb{1}_{A_i = a}}$$
其中$1_{predicate}$表示随机变量，当predicate为真时，其值为1，反之为0，当分母为0时，将$Q_t(a)$定义为某个默认值，比如0，当分母趋向无穷大时，根据大数定律，$Q_t(a)$会收敛到$q_*(a)$，我们将这种方法称为采样平均方法，因为每一次估计都是对相关样本收益的平均<br>
最简单的动作选择规则是选择具有最高估计值的动作，即前一节所定义的贪心动作，如果有多个贪心动作，那就任意选择一个，比如随机挑选，我们将这种贪心动作的选择方法记作$$A_t = \arg \max_a Q_t(a)$$，其中$\arg\max_a$是使得$Q_t(a)$值最大的动作a，选择的贪心动作总是利用当前的知识最大化眼前的收益，这种方法根本不花时间去尝试明显的劣质动作，看看它们是否真的会更好<br>
贪心的一个简单的替代策略是大部分时间都表现的贪心，但偶尔（比如一个很小的概率$\epsilon$）以独立于动作——价值估计值的方式从所有动作中等概率随机的做出选择，我们将这种近乎贪心的选择规则称为$\epsilon-$贪心方法，这个方法的一个优点是，如果时刻可以无限长，则每个动作都会被无限次采样，从而确保所有的$Q_t(a)$收敛到$q_*(a)$，这当然也意味着选择最优动作的概率会收敛到大于$1-\epsilon$，即接近确定性选择，然而这只是渐进性的保证，并且鲜有人提到这种方法的实际效果
### 3. 10臂测试平台
比较贪心方法和两种$\epsilon-$贪心方法（$\epsilon = 0.01, \epsilon = 0.1$）所有方法都采样平均策略来形成对动作价值的估计，上部的图显示了：
- 期望的收益随着经验的增长而增长
- 贪心方法在最初增长的略微快一些，但是随后稳定在一个较低的水平，但随后稳定在一个较低的水平
- 从长远来看，贪心的方法明显表现的更糟，因为经常陷入执行次优动作的怪圈
- $\epsilon-$贪心方法最终表现更好，因为它们持续的试探并提升找到最优动作的机会
- $\epsilon = 0.1$的方法试探得更多，通常更早的发现最优的动作，但是在每时刻选择这个最优动作的概率却永远不超过91%
- $\epsilon = 0.01$的方法改善得更慢，但是在途中两种测度下，最终的性能都会比$\epsilon = 0.1$的方法更好
- 为了充分利用高和低的$\epsilon$值的优势，随着时刻的推移来逐步减少$\epsilon$也是可以的

$\epsilon-$贪心算法相对于贪心算法的优点依赖于任务：
- 假设收益的方差更大，由于收益的噪声更多，所以为了找到最优的动作需要更多次的试探，而$\epsilon-$贪心算法会比贪心算法好很多
- 但是如果收益的方差为0，那么贪心方法会在尝试一次之后就知道每一个动作的真实价值，在这种情况下，贪心方法实际上可能表现最好，因为它很快就能找到最佳的动作，然后再也不会进行试探
- 即使在有确定性的情况下，如果弱化一些假设，对试探也有很大的好处，假设赌博机是非平稳的，即动作的真实价值会随着时间而变化，在这种情况下试探是需要的，这是为了确认某个非贪心的动作不会变得比贪心的动作更好
### 4. 增量式实现
如何才能以一种高效的方式计算这些均值，尤其是如何保持常数级的内存需求和常数级的单时刻计算量<br>
为了简化标记，我们关心每个动作，令$R_i$表示这一动作被选择i次后获得的收益，$Q_n$表示被选择n-1次后它的估计的动作价值，现在可以简单的把它写为$$Q_n = \frac{R_1+R_2+···+R_{n-1}}{n-1}$$，这种简明的实现需要维护所有的收益记录，然后再每次需要估计价值时进行计算，然而由于已知的收益越来越多，内存和计算量会随着时间增长，每增加一次收益就需要更多的内存存储和更多的计算资源来对分子求和<br>
均值的另一种计算方式：
$$
\begin{aligned}
Q_{n+1} &= \frac{1}{n} \sum_{i=1}^n R_i \\
&= \frac{1}{n} (R_n + \sum_{i=1}^{n-1}R_i) \\
&= \frac{1}{n} (R_n + (n-1)\frac{1}{n-1} \sum_{i=1}^{n-1}R_i) \\
&= \frac{1}{n} (R_n + (n-1)Q_n) \\
&= \frac{1}{n} (R_n + nQ_n - Q_n) \\
&= Q_n + \frac{1}{n}[R_n - Q_n]
\end{aligned}
$$
这个式子即使对n=1也有效，对任意$Q_1$，可以得到$Q_2 = R_1$，对于每一个新收益，这种实现只需要存储$Q_n$和n，和上述公式的少量计算<br>
上述式子的一般形式是：$$新估计值 = 旧估计值 + 步长 \times [目标 - 旧估计值]$$
表达式[目标 - 旧估计值]是估计值的误差，误差会随着向“目标”靠近的每一步而减少，虽然“目标”中可能充满噪声，但我们还是假定“目标”会告诉我们可行的前进方向<br>
值得注意的是，上述增量式方法中的“步长”会随时间而变化，处理a对应的第n个收益的方法用的“步长”是$\frac{1}{n}$，在本书中将“步长”记作$\alpha$，或者更普适的记作$\alpha_t(a)$
一个完整的使用以增量式计算的样本均值和$\epsilon-$贪心动作选择的赌博机算法的伪代码如下面的框中所示，假设函数bandit(a)接受一个动作作为参数并且返回一个对应的收益
>初始化，令a = 1到k：<br>
>$Q(a) \leftarrow 0$<br>
>$N(a) \leftarrow 0$<br>
>无限循环：<br>
>$
>A \leftarrow
>\begin{cases}
>\arg \max_a Q(a) 以1-\epsilon概率（随机跳出贪心）\\

>\end{cases}
>$<br>

### 5. 跟踪一个非平稳问题
取平均方法对平稳的赌博机问题是合适的，即收益的概率分布不随着时间变化的赌博机问题，但如果赌博机的收益概率是随着时间变化的，该方法就不合适，在这种情形下，给近期的收益赋予比过去很久的收益更高的权值就是一种合理的处理方式，最流行的方法之一是使用固定步长：
$$Q_{n+1} = Q_n + \alpha[R_n - Q_n]$$
式中步长参数$\alpha \in (0, 1]$是一个常数，这使得$Q_{n+1}$成为对过去的收益和初始的估计$Q_1$的加权平均
$$Q_{n+1} = (1 - \alpha)^nQ_1 + \sum_{i=1}^n \alpha(1-\alpha)^{n-i}R_i$$
赋给$R_i$的权值$\alpha(1-\alpha)^{n-i}$依赖于它被观察到的具体时刻与当前时刻的差，即n-i，$1-\alpha$小于1，因此赋予$R_i$的权值随着相隔次数的增加而以指数形式递减，这个方法有时候也被称为“指数近因加权平均”<br>
有时候随着时刻一步步改变步长参数是很方便的，设$\alpha_n(a)$表示用于处理第n次选择动作a后收到的收益的步长参数，选择$\alpha_n(a) = \frac{1}{n}$将会得到采样平均法，大数定律保证它可以收敛到真值（真实参数），然而收敛性当然不能保证对任何$\{\alpha_n(a)\}$序列都满足，随机逼近理论中一个著名结果给出了保证收敛概率为1所需的条件$$\sum^{\infty}_{n=1} \alpha_n(a) = \infty且\sum^{\infty}_{n=1}\alpha_n^2(a) < \infty$$，第一个条件是要求保证有足够大的步长，最终克服任何初始条件或随机波动，第二个条件保证最终步长变小，以保证收敛<br>
常数步长$\alpha_n(a) = \alpha$中不满足，第二个条件无法满足，说明估计永远无法完全收敛，而是会随着最近得到的收益而变化，在非平稳环境中这是我们想要的，而且强化学习中的问题实际上常常是非平稳的，此外，符合上述式子的步长参数序列往往收敛的很慢，或者需要大量的调试才能得到一个满意的收敛率，尽管在理论工作中很常用，但是符合这些收敛条件的步长参数序列在实际应用和实验研究中很少用到
### 6. 乐观初始值
目前讨论的所有方法都在一定程度上依赖于初始动作值$Q_1(a)$的选择，从统计学角度来说，这些方法（由于初始估计值）是有偏的
- 对于采样平均法来说，当所有动作都至少被选择一次时，偏差就会消失
- 但对于步长为常数$\alpha$的情况，给出的偏差会随时间减少，但不会消失

在实际中，这种偏差通常不是一个问题，有时甚至会很有好处，缺点是如果不将它们全部设置为0，则初始估计值实际上变成了一个必须由用户选择的参数集，好处是通过它们可以简单的设置关于预期收益水平的先验知识<br>
将原先初始值0替换为+5，是一个过度乐观的估计，但是这种乐观的初始估计却会鼓励动作——价值方法去试探，因此无论哪一种动作被选择，收益都比最开始的估计值要小，因此学习器会对得到的收益感到失望，从而转向另一个动作，结果是所有动作在估计值收敛之前都被尝试了好几次，即使每一次都按照贪心法选择动作，系统也会进行大量试探，这种试探的技术叫做乐观初始价值：
- $Q_1(a) = +5$，并使用贪心算法：刚开始表现的比较糟糕，因为它需要试探许多次，但是最终随着时间的推移，试探的次数减少，它的表现也更好
- $Q_1(a) = 0$，$\epsilon-$贪心算法，$\epsilon = 0.1$：反之

这是一个简单的技巧，在平稳问题中非常有效，但它远非鼓励试探的普遍有用的方法，它不太适合非平稳问题，因为它试探的驱动力天生是暂时的，如果任务发生了变化，对试探的需求变了，则这种方法就无法提供帮助<br>
事实上任何仅仅关注初始条件的方法都不太可能对一般的非平稳情况有所帮助<br>
无偏恒定步长技巧：既利用恒定步长方法在非平稳过程中的优势，又能有效避免它的偏差<br>
利用如下的步长来处理某个特定动作的第n个收益$$\beta_n \doteq \frac{\alpha}{\bar{o}_n}$$，其中$\alpha > 0$是一个传统的恒定步长，$\bar{o}_n$是一个从零时刻开始计算的修正参数$$\bar{o}_n \doteq \bar{o}_{n-1} + \alpha(1 - \bar{o}_{n-1}),对n \geq 0,满足\bar{o}_0 \doteq 0$$
### 7. 基于置信度上界的动作选择
$\epsilon-$贪心算法会尝试选择非贪心的动作，但这是一种盲目的选择，因为它不大会去选择接近贪心或者不确定性特别大的动作<br>
在非贪心动作中，最好是根据它们的潜力来选择可能事实上是最优的动作，这就要考虑到它们的估计有多接近最大值，以及这些估计的不确定性<br>
一个有效的方法是按照以下公式选择动作：$$A_t = \arg \max_a \left[Q_t(a)+c\sqrt{\frac{\ln t}{N_t(a)}}\right]$$，在这个公式里，$N_t(a)$表示在时刻t之前动作a被选择的次数，c是一个大于0的数，它控制试探的程度，如果$N_t(a) = 0$，则a就被认为是满足最大化条件的动作<br>
这种基于置信度上界（UCB）的动作选择的思想是：
- 平方根项是对a动作值估计的不确定性或方差的度量，因此最大值的大小是动作a的可能真实值的上限，参数c决定了置信水平
- 每次选a时，不确定性可能会减小，由于$N_t(a)$出现在不确定项的分母上 ，因此随着$N_t(a)$的增加，这一项就减少了
- 每次选择a之外的动作时，在分子上的t增大，而$N_t(a)$却没有发生变化，所以不确定性增加了
- 自然对数意味着随着时间的推移，增加会变得越来越小，但它是无限的
- 所有动作最终都将被选中，但是随着时间的流逝，具有较低价值估计的动作或者已经被选择了更多次的动作被选择的频率较低
### 8. 梯度赌博机算法
针对每个动作a考虑一个数值化的偏好函数$H_t(a)$，偏好函数越大，动作就越频繁的被选择，但偏好函数的概念并不是从“收益”的意义上提出的，只有一个动作对另一个动作的相对偏好才是重要的，如果给每一个动作的偏好函数都加上1000，那么按照softmax（吉布斯或玻尔兹曼分布）确定的动作概率将没有影响
$$Pr\{A_t = a\} = \frac{e^{H_t(a)}}{\sum_{b = 1}^k e^{H_t(b)}} = \pi_t(a)$$
其中$\pi_t(a)$用来表示动作a在时刻t时被选择的概率，所有偏好函数的初始值都是一样的，所以每个动作被选择的概率是一样的<br>
基于随机梯度上升的思想，本文提出了一种自然学习算法，在每个步骤中，在选择动作$A_t$并获得收益$R_t$时，偏好函数将会按如下方式进行更新：
$$H_{t+1}(A_t) = H_t(A_t) + \alpha(R_t - \bar{R_t})(1 - \pi_t(A_t))，以及$$
$$H_{t+1}(a) = H_t(a) - \alpha(R_t - \bar{R_t})\pi_t(a)，对所有 a \neq A_t$$
其中$\alpha$是一个大于0的数，表示步长，$\bar{R_t} \in \R$是在时刻t内所有收益的平均值，可以逐步计算，$\bar{R_t}$项作为比较收益的一个基准项，如果收益高于它 ，那么未来选择动作$A_t$的概率就会增加，反之概率就会降低，未选择的动作被选择的概率上升
### 9. 关联搜索（上下文相关的赌博机）
目前只考虑了非关联的任务，对它们来说没有必要将动作与与不同的情境联系起来，在这些任务中，当任务是平稳的时候，学习器会试图寻找一个最佳的动作，当任务是非平稳的时候，最佳动作会随着时间的变化而改变，此时它会试着去追踪最佳动作<br>
然而，在一般的强化学习任务中，往往有不止一种情境，它们的目标是学习一种策略：一个从特定情境到最优动作的映射<br>
关联搜索任务现在通常被称为上下文相关的赌博机，介于k臂赌博机问题和完整的强化学习问题之间
- 它与完整强化学习的相似点是，它需要学习一种策略
- 它又与k臂赌博机问题相似，体现在每个动作只影响即时收益，如果允许动作可以影响下一时刻的情境或收益，那么这就是完整的强化学习问题

## 第三章：有限马尔可夫决策过程<a id = "第三章"></a>
### 1. “智能体——环境”交互接口
MDP就是一种通过交互式学习来实现目标的理论框架
- 进行学习及实施决策的机器被称为智能体，智能体之外所有与其相互作用的事物被称为环境
- 这些事物之间持续进行交互，智能体选择动作，环境对这些动作做出相应的响应，并向智能体呈现新的状态 
- 环境也会产生一个特定的收益，通常是特定的数值，这就是智能体在动作选择过程中想要最大化的目标

MDP和智能体共同给出了一个序列或轨迹：$S_0,A_0,R_1,S_1,A_1,R_2,S_2,A_2,R_3,...$<br>
在有限MDP中，状态、动作和收益的集合（$\mathcal{S, A, R}$）都只有有限个元素，在这种情况下，随机变量$R_t$和$S_t$具有定义明确的离散概率分布，并且只依赖于前继状态和动作的值，这些随机变量的特定值，$s' \in \mathcal{S}$和$r \in \mathcal{R}$，在t时刻出现的概率是$$p(s',r|s,a) \doteq Pr\{S_t = s',R_t = r|S_{t-1} = s,A_{t-1} = a\}$$
对于任意$s, s' \in \mathcal{S}, r \in \mathcal{R}$以及$a \in \mathcal{A}(s)$，函数p定义了MDP的动态特性，函数p为每个s和a的选择都指定了一个概率分布，即$$\sum_{s' \in \mathcal{S}}\sum_{r \in \mathcal{R}} p(s',r|s,a) = 1,对于所有s \in \mathcal{S},a \in \mathcal{A}(s)$$
在马尔可夫决策过程中，由p给出的概率完全刻画了环境的状态特性，也就是说$S_t$和$R_t$的每个可能的值出现的概率只取决于前一个状态$S_{t-1}$和前一个动作$A_{t-1}$，并且与更早之前的状态和动作完全无关，这个限制不是针对决策过程，而是针对状态的，状态必须包括过去智能体和环境交互的方方面面的信息，这些信息会对未来产生一定的影响，这样状态就被认为具有马尔可夫性<br>
从四参数动态函数p中，我们可以计算出关于环境的任何其他信息，例如：
- 状态转移概率（我们将其表示为一个三参数函数p：$\mathcal{S \times S \times A} \rightarrow [0, 1]$）$$p(s'|s,a) \doteq Pr\{S_t = s'|S_{t-1} = s,A_{t-1} = a\} = \sum_{r \in \mathcal{R}}p(s',r|s,a)$$
- “状态——动作”二元组期望收益，并将其表示为一个双参数函数r： $\mathcal{S} \times \mathcal{A} \rightarrow \R$ $$r(s,a) \doteq \mathbb{E}[R_t|S_{t-1} = s, A_{t-1} = a] = \sum_{r \in \mathcal{R}}r\sum_{s' \in \mathcal{S}}p(s',r|s,a)$$
- “状态——动作——后继状态”三元组的期望收益，并将其表示为一个三参数函数r：$\mathcal{S \times A \times S} \rightarrow \R$ $$r(s,a,s') \doteq \mathbb{E}[R_t|S_{t-1} = s,A_{t-1} = a, S_t = s'] = \sum_{r \in \mathcal{R}}r \frac{p(s',r|s,a)}{p(s'|s,a)}$$
智能体和环境之间的界限通常与机器人或动物身体的物理边界不同，一般情况下，这个界限离智能体更近，我们遵循的一般规则是，智能体不能改变的事物都被认为是外部的，即是环境的一部分，但我们并不是假定智能体对环境一无所知，智能体通常会知道如何通过一个动作和状态的函数来计算所得到的收益，但是我们通常认为收益的计算在智能体的外部，因为它定义了智能体所面临的任务，因此智能体必然无法随意改变它<br>
事实上，在某些情况下，智能体可能了解环境的一切工作机制，然而即便如此，它面临的强化学习任务仍然是困难的<br>
智能体和环境的界限划分仅仅决定了智能体进行绝对控制的边界，并不是其知识的边界<br>
出于不同的目的，智能体——环境的界限可以被放在不同的位置，在一个复杂的机器人里，多个智能体可能会同时工作，但它们各自有各自的界限<br>
MDP框架是目标导向的交互式学习问题的一个高度抽象，它提出无论感官、记忆和控制设备细节如何，无论要实现何种目标，任何目标导向的行为的学习问题都可以概括为智能体及其环境之间来回传递三个信号：
- 一个信号用来表示智能体做出的选择（行动）
- 一个信号用来表示做出该选择的基础（状态）
- 一个信号用来定义智能体的目标（收益）

对于不同的任务，特定的状态和动作的定义差异很大，并且性能极易受其表征方式的影响，与其他类型的学习一样
### 2. 目标和收益
在强化学习中，智能体的目标被形式化表征为一种特殊信号，称为收益，它通过环境传递给智能体，在每个时刻，收益都是一个单一标量数值，$R_t \in \R$，非正式的说，智能体的目标是最大化其受到的总收益，这意味着需要最大化的不是当前收益，而是长期积累的收益<br>
收益假设：我们所有的“目标”或“目的”都可以归结为：最大化智能体接收到的标量信号（称之为收益）累积和的概率期望值<br>
使用收益信号来形式化目标是强化学习最显著的特征之一，如果我们想要它为我们做某件事，我们提供收益的方式必须要使得智能体在最大化收益的同时也实现我们的目标<br>
因此，至关重要的一点就是，我们设立收益的方式要能真正表明我们的目标，特别的，收益信号并不是传授智能体如何实现目标的先验知识，收益信号只能用来传达什么是你想要实现的目标，而不是如何实现这个目标
### 3. 回报和分幕
一般来说我们寻求的是最大化期望回报，记为$G_t$，它被定义为收益序列的一些特定函数，在最简单的情况下，回报是收益的总和$$G_t \doteq R_{t+1} + R_{t+2} + R_{t+3} + ··· + R_T$$，其中T是最终时刻，这种方法在有“最终时刻”这种概念的应用中是有意义的，在这类应用中，智能体和环境的交互能被自然地分成一系列子序列（每个序列都存在最终时刻），我们称每个子序列为幕（有时也被称为试验），每幕都以一种特殊状态结束，称之为终结状态，随后会重新从某个标准的起始状态或起始状态的分布中的某个状态样本开始，即使结束的方式不同，下一幕的开始状态与上一幕的结束方式完全无关，因此这些幕可以被认为在同样的终结状态结束，只是对不同的结果有不同的收益，具有这种分幕重复特性的任务称为分幕式任务，在分幕式任务中，我们有时需要区分非终结状态集，记为$\mathcal{S}$，和包含终结与非终结状态的所有状态集，记作$\mathcal{S}^+$，终结的时间T是一个随机变量，通常随着幕的不同而不同<br>
另一方面，在许多情况下，智能体——环境交互不一定能被自然的分为单独的幕，而是持续不断地发生，我们称这些任务为持续性任务<br>
回报公式用于描述持续性任务时会出现问题，因为最终时刻$T = \infty$，并且我们试图最大化的回报也很容易趋于无穷，因此我们需要引入一个额外的概念，即折扣，根据这种方法，智能体尝试选择动作，使得在未来收到的经过折扣系数加权后的收益总和是最大化的，特别的，它选择$A_t$来最大化期望折后回报
$$G_t \doteq R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + ··· = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}$$
其中$\gamma$是一个参数，$0 \leq \gamma \leq 1$，被称为折扣率<br>
折扣率决定了未来收益的现值：未来k时刻的收益值只有它的当前值的$\gamma^{k-1}$倍
- 如果$\gamma < 1$，那么只要收益序列$\{R_{k}\}$有界，式中的无限序列总和就是一个有限值
- 如果$\gamma = 0$，那么智能体是“目光短浅的”，即只关心最大化当前利益，在这种情况下，其目标是学习如何选择$A_t$来最大化$R_{t+1}$，如果每个智能体的行为都碰巧只影响当前收益，而不是未来的回报，那么目光短浅的智能体可以通过单独最大化每个收益来最大化整个式子，但一般来说，最大化当前收益会减少未来收益，以至于实际上的收益变少了
- 随着$\gamma$接近1，折后回报将更多的考虑未来的收益，也就是说智能体变得更有远见了

邻接时刻的回报可以用如下递归方式相互联系起来
$$
\begin{aligned}
G_t &\doteq R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \gamma^3 R_{t+4} + ··· \\
&= R_{t+1} + \gamma(R_{t+2} + \gamma R_{t+3} + \gamma^2 R_{t+4} + ···) \\
&= R_{t+1} + G_{t+1}
\end{aligned}
$$
如果定义$G_T = 0$，那么上式会适用于任意时刻$t < T$，即使最终时刻出现在t+1也不例外，这通常会让我们从收益序列中计算回报的过程变得更简单
### 4. 分幕式和持续性任务的统一表示法
本文需要考虑一系列“幕序列”，每一幕都由有限的时刻组成，对每一幕的时刻，我们都要从0开始标号，因此我们不能简单的将时刻t的状态表示为$S_t$，而是要区分它所在的幕，要使用$S_{t,i}$来表示幕i中时刻t的状态<br>
然而事实证明，当我们讨论分幕式任务时，我们不必区分不同的幕，我们几乎总是通过删除幕编号的显式引用，来略微的滥用符号，我们会用$S_t$来表示$S_{t,i}$等<br>
使用另一个约定来获得一个统一的符号，它可以同时适用于分幕式和持续性任务，这两者可以通过一个方法进行统一，即把幕的终止当作一个特殊的吸收状态的入口，它只会转移到自己并且只产生零收益，因而可以把回报表示为：
$$G_t \doteq \sum^T_{k=t+1} \gamma^{k-t-1} R_k$$
并允许上式包括$T = \infty$或$\gamma = 1$（但不是二者同时）的可能性
### 5. 策略和价值函数
价值函数是状态（或状态与动作二元组）的函数，用来评估智能体在给定状态（或给定状态与动作）下有多好<br>
这里“有多好”的概念是用未来预期收益来定义的，或者更准确的说，就是回报的期望值，当然智能体期望未来能得到的收益取决于智能体所选择的动作，因此价值函数是与特定的行为方式相关的，我们称之为策略<br>
严格来说，策略是从状态到每个动作的选择的概率之间的映射，如果智能体在时刻t选择的策略$\pi$，那么$\pi (a|s)$就是当$S_t = s$时$A_t = a$的概率，就像p一样，$\pi$只是一个普通的函数，强化学习方法规定了智能体的策略如何随着其经验而发生变化<br>
我们把策略$\pi$下状态s的价值函数记为$v_\pi(s)$，即从状态s开始，智能体按照策略$\pi$进行决策所获得的回报的概率期望值，对于MDP，可以定义$v_\pi$为
$$v_\pi(s) \doteq \mathbb{E}_\pi [G_t|S_t = s] = \mathbb{E}_\pi \left[\sum_{k=0}^{\infty} \gamma^k R_{t+k+1}|S_t = s\right]，对于所有s \in \mathcal{S}$$
其中$\mathbb{E}_\pi[·]$表示在给定策略$\pi$时一个随机变量的期望值，t可以是任意时刻，终止状态的价值始终为0，我们把函数$v_\pi$称为策略$\pi$的状态价值函数<br>
类似的，我们把策略$\pi$在状态s时采取的动作a的价值记为$q_\pi(s,a)$，这就是根据策略$\pi$，从状态s开始，执行动作a之后，所有可能的决策序列的期望回报
$$q_\pi(s,a) \doteq \mathbb{E}_\pi[G_t|S_t = s, A_t = a] = \mathbb{E}_\pi \left[\sum_{k=0}^{\infty} \gamma^k R_{t+k+1}|S_t = s,A_t = a\right]$$
我们称$q_\pi$为策略$\pi$的动作价值函数<br>
价值函数$v_\pi$和$q_\pi$都能从经验中估算得到，当然当环境中有很多状态时，独立的估算每个状态的平均值时不切实际的，在这种情况下，我们可以将$v_\pi$和$q_\pi$进行参数化（参数的数量要远少于状态的数量），然后通过调整价值函数的参数来更好的计算回报值，将价值函数参数化也有可能得到精确的估计，但是这取决于参数化的近似函数的特性<br>
在强化学习和动态规划中，价值函数有一个基本特性，就是它们满足某种递归关系，类似于我们前面为回报建立的递归公式，对于任何策略$\pi$和任何状态s，s的价值与其可能的后继状态的价值之间存在一下关系
$$
\begin{aligned}
v_\pi(s) &\doteq \mathbb{E}_\pi [G_t|S_t = s] \\
&= \mathbb{E}_\pi [R_{t+1} + \gamma G_{t+1} | S_{t+1} = s'] \\
&= \sum_a \pi(a|s) \sum_{s'}\sum_r p(s',r|s,a)[r+\gamma\mathbb{E}_\pi[G_{t+1}|S_{t+1} = s']] \\
&= \sum_a \pi(a|s)\sum_{s',r}p(s',r|s,a)[r+\gamma v_\pi(s')]，对所有s \in \mathcal{S}
\end{aligned}
$$
其中动作a取自集合$\mathcal{A}(s)$，下一时刻状态s'取自集合$\mathcal{S}$（在分幕式的问题中，取自集合$\mathcal{S^+}$），收益值r取自集合$\mathcal{R}$<br>
对于每个三元组，我们首先计算$\pi(a|s)p(s',r|s,a)$，并用该概率对括号内的数值进行加权，然后对所有可能取值求和得到最终的期望值<br>
上述式子被称作$v_\pi$的贝尔曼方程，它用等式表达了状态价值和后继状态价值之间的关系<br>
从状态s开始，并将其作为根节点，智能体可以根据其策略$\pi$，采取动作集合中的任意一个动作，对于每一个动作，环境会根据其动态特性函数p，以及一个后继状态s'及其收益r作为响应，贝尔曼方程对所有可能性采用其出现概率进行了加权，这也就说明了起始状态的价值一定等于后继状态的（折扣）期望值加上对应的收益期望值<br>
价值函数$v_\pi$是贝尔曼方程的唯一解，将类似以上树状图的图叫做回溯图，图中的关系是回溯运算的基础 ，回溯操作就是将后继状态（或“状态——动作”二元组）的价值信息回传给当前时刻的状态（或“状态——动作”二元组）
### 6. 最优策略和最优价值函数
在本质上，价值函数定义了策略上的一个偏序关系，若对于所有$s \in \mathcal{S}, \pi \geq \pi'$，那么应当$v_\pi(s) \geq v_{\pi'}(s)$，总会存在至少一个策略不劣于其他所有策略，这就是最优策略，尽管最优策略可能不止一个，我们还是用$\pi_*$来表示所有这些最优策略，它们共享相同的状态价值函数，称之为最优状态价值函数，记为$v_*$，其定义为：对于任意$s \in \mathcal{S}$，$$v_*(s) \doteq \max_{\pi}v_\pi(s)$$，最优的策略也共享相同的最优动作价值函数，记为$q_*$，其定义为：对于任意$s \in \mathcal{S}, a \in \mathcal{A}$，$$q_*(s,a) \doteq \max_\pi q_\pi(s,a)$$，对于所有“状态——动作”二元组(s,a)，这个函数给出了在状态s下，先采取动作a，之后按照最优策略去决策的期望回报，因此我们可以用$v_*$来表示$q_*$，如下所示$$q_*(s,a) = \mathbb{E}[R_{t+1} + \gamma v_*(S_{t+1})|S_t = s, A_t = a]$$
因为$v_*$是策略的价值函数，它必须满足贝尔曼方程中状态和价值的一致性条件，但因为它是最优的价值函数，所以$v_*$的一致性条件可以用一种特殊的形式表示，而不拘泥于任何特定的策略，这就是贝尔曼最优方程，我们可以直观的理解为，贝尔曼最优方程阐述了一个事实：最优策略下各个状态的价值一定等于这个状态下最优动作的期望回报
$$
\begin{aligned}
v_*(s) &= \max_{a \in \mathcal{A(s)}} q_{\pi_*}(s,a) \\
&= \max_a \mathbb{E}_{\pi_*} [G_t | S_t = s, A_t = a] \\
&= \max_a \mathbb{E}_{\pi_*}[R_{t+1} + \gamma G_{t+1} | S_t = s, A_t = a] \\
&= \max_a \mathbb{E}[R_{t+1} + \gamma v_*(S_{t+1}) | S_t = s, A_t = a]
&= \max_a \sum_{s', r} p(s', r|s, a)[r + \gamma v_*(s')]
\end{aligned}
$$
最后两个等式就是$v_*$的贝尔曼最优方程的两种形式，$q_*$的贝尔曼最优方程如下
$$
\begin{aligned}
q_*(s|a) &= \mathbb{E}[R_{t+1} + \gamma \max_{a'}q_*(S_{t+1},a')|S_t = s, A_t = a] \\
&= \sum_{s', r}p(s', r|s, a)[r + \gamma \max_{a'} q_*(s', a')]
\end{aligned}
$$
对于优先MDP来说，$v_\pi$的贝尔曼最优方程有独立于策略的唯一解，贝尔曼最优方程实际上是一个方程组，每个状态对应一个方程等式，也就是说，如果有n个状态，那么n个含有n个未知量的方程，如果环境的动态变化特性p是已知的，那么原则上可以用解非线性方程组的方法来求解$v_*$方程组，类似的，我们可以求得$q_*$的一组解<br>
一旦有了$v_*$，确定一个最优策略就比较容易了，对于每个状态s，都存在一个或多个动作，可以在贝尔曼最优方程的条件下产生最大的价值，如果在一个策略中，只有这些动作的概率非零，那么这个策略就是一个最优策略，可以将其视为一个单步搜索，如果最优价值函数$v_\pi$已知，那么单步搜索后的最好的动作就是全局最优动作，换句话说，对于最优价值函数$v_*$来说，任何贪心策略都是最优策略<br>
在给定$q_*$的情况下，选择最优动作的过程变得更加容易，给定$q_*$，智能体甚至不需要进行单步搜索的过程，也就是说，对于任意状态s，智能体只要找到使得$q_*(s,a)$最大化的动作a就可以了，动作价值函数有效的保存着所有单步搜索的结果，它将最优的长期回报的期望值表达为对应每个“状态——动作”二元组的一个当前局部量，因此将价值函数表达为“状态——动作”二元组的函数不仅仅是状态的函数后，最优动作的选取就不再需要知道后继状态和其对应的价值了<br>
显式求解贝尔曼最优方程给出了一个找到最优策略的方法，也就是一个解决强化学习问题的方法，但是这个方法很少是直接有效的，至少依赖于三条在实际情况下很难满足的假设
1. 我们准确的知道环境的动态变化特性
2. 有足够的计算资源来求解
3. 马尔可夫性质

对于我们感兴趣的任务来说，如果不能满足这些假设中的其中一项，就不能用这个方法来求解
### 7. 最优性和近似算法
- 最优策略通常需要极大量的计算资源，真实情况下的智能体只能采用不同程度的近似方法
- 存储容量也是一个很重要的约束
    - 表格型算法：价值函数、策略和模型的估计通常需要大量的存储空间，在状态集合小而有限的任务中，用数组或者表格来估计每个状态（或“状态——动作”二元组）是有可能的，这类任务被称为表格型任务，对应的方法称之为表格型方法
    - 近似算法：经常有很多状态时不能用表格中的一行表示，价值函数必须采用近似算法，这时通常用紧凑的参数化函数表示方法

强化学习在线运行的本质使得它在近似最优策略的过程中，对于那些经常出现的状态集合会花更多的努力去学习好的决策，这是区分强化学习和其他解决MDP问题的近似方法的一个重要判断依据

## 第四章：动态规划<a id = "第四章"></a>
传统DP算法的作用有限的原因：
- 一个完备的环境模型只是一个假设
- 计算复杂度极高

在本章中假设环境是一个有限MDP，即$\mathcal{S、A、R}$是有限的，并且整个系统的动态特性由对于任意$s \in \mathcal{S}、a \in \mathcal{A}(s)、r \in \mathcal{R}、s' \in \mathcal{S^+}$的四参数概率分布$p(s', r|s, a)$给出<br>
在强化学习中，DP的核心思想是使用价值函数来结构化的组织对最优策略的搜索<br>
一旦我们得到了满足贝尔曼最优方程的价值函数$v_*$或$q_*$，得到最优策略就很容易了<br>
通过将贝尔曼方程转化成为近似逼近理想价值函数的递归更新公式，我们就得到了DP算法
### 1. 策略评估（预测）
对于任意一个策略$\pi$，如何计算其状态价值函数$v_\pi$，这被称为策略评估，有时也称其为预测问题
$$
\begin{aligned}
v_\pi(s) &\doteq \mathbb{E}_\pi [G_t|S_t = s] \\
&= \mathbb{E}_\pi [R_{t+1} + \gamma G_{t+1} | S_{t+1} = s'] \\
&= \sum_a \pi(a|s) \sum_{s'}\sum_r p(s',r|s,a)[r+\gamma\mathbb{E}_\pi[G_{t+1}|S_{t+1} = s']] \\
&= \sum_a \pi(a|s)\sum_{s',r}p(s',r|s,a)[r+\gamma v_\pi(s')]，对所有s \in \mathcal{S}
\end{aligned}
$$
其中，$\pi(a|s)$指的是处于环境状态s时，智能体在策略$\pi$下采取的动作a的概率，期望下标$\pi$表明期望的计算是以遵循策略$\pi$为前提条件的，只要$\gamma < 1$或者任何状态在$\pi$下都能保证最后终止，那么$v_\pi$唯一存在<br>
如果环境的动态特性完全已知，那么上式就是一个有着$|\mathcal{S}|$个未知数$(v_\pi(s), s \in \mathcal{S})$以及$|\mathcal{S}|$个等式的联立线性方程组<br>
使用迭代法来解决这个问题，考虑一个近似的价值函数序列，$v_0,v_1,v_2,...,$从$S^+$映射到实数集$\R$（实数集）。初始的近似值$v_0$可以任意选取（除了终止状态值必须为0外）。然后下一轮迭代的近似使用$v_\pi$的贝尔曼方程进行更新，显然$v_k = v_\pi$是这个更新规则的一个不动点，因为$v_\pi$的贝尔曼方程已经保证了这种情况下的等式成立，事实上，在保证$v_\pi$存在的条件下，序列$\{v_k\}$在$k \rightarrow \infty$时将会收敛到$v_\pi$，这个算法叫做迭代策略评估<br>
期望更新：对每个状态s采用相同的操作，根据给定的策略，得到所有可能的单步转移之后的即时收益和s的每个后继状态的旧的价值函数，利用这二者的期望值来更新s的新的价值函数
- 使用状态进行更新
- 使用“状态——动作”二元组进行更新
- 取决于后继状态的价值函数的具体组合方式

实现迭代策略评估需要使用两个数组：
- 一个用于存储旧的价值函数$v_k(s)$
- 一个存储新的价值函数$v_{k+1}(s)$
- 或者使用“就地”更新

迭代策略评估的完整的就地更新的版本
>输入待评估的策略$\pi$<br>
>算法参数：小阈值$\theta > 0$，用于确定估计量的精度<br>
>对于任意$s \in \mathcal{S^+}$，任意初始化$V(s)$，其中$V(终止状态) = 0$<br>
>循环：<br>
>$\quad \Delta \leftarrow 0$<br>
>$\quad$对每一个$s \in \mathcal{S}$循环：<br>
>$\quad \quad v \leftarrow V(s)$<br>
>$\quad \quad V(s) \leftarrow \sum_a \pi(a|s) \sum_{s',r} p(s', r|s, a)[r + \gamma V(s')]$<br>
>直到$\Delta < \theta$

从形式上来说，迭代策略评估只能在极限意义上收敛，但实际上它必须在此之前停止
### 2. 策略改进
如果从状态s继续使用现有策略，那么最后的结果就是$v_\pi(s)$，但是我们不知道如果换成一个新策略的话，会得到更好还是更坏的结果<br>
一种解决方法是在状态s选择动作a后，继续遵循现有的策略$\pi$，这种方法的值为：
$$q_\pi \doteq \mathbb{E} [R_{t+1} + \gamma v_\pi(S_{t+1})|S_t = s, A_t = a] = \sum_{s', r} p(s', r|s, a)[r + \gamma v_\pi(s')]$$
一个关键的准则就是这个策略大于还是小于$v_\pi(s)$，如果这个值更大，则说明在状态s选择一次动作a，然后继续使用策略$\pi$会比始终使用策略$\pi$更优，事实上，我们期望的是在每次选择遇到状态s的时候，选择动作a总可以达到更好的结果，这个时候，我们就认为这个新策略总体来说更好<br>
策略改进定理：一般来说，如果$\pi$和$\pi'$是任意的两个确定的策略，对任意$s \in \mathcal{S}, q_\pi(s, \pi'(s)) \geq v_\pi(s)$，那么我们称策略$\pi'$相比于$\pi$一样好或者更好，也就是说对于任意状态$s \in \mathcal{S}$，这样肯定能得到一样或更好的期望回报$v_\pi'(s) \geq v_\pi(s)$，两个式子同时取等号<br>
策略改进：考虑一个新的贪心策略满足
$$
\begin{aligned}
\pi'(s) &\doteq \argmax_a q_\pi(s, a) \\
&= \argmax_a \mathbb{E} [R_{t+1} + \gamma v_\pi(S_{t+1})|S_t = s, A_t = a] \\
&= \argmax_a \sum_{s', r} p(s', r|s, a)[r + \gamma v_\pi(s')]
\end{aligned}
$$
这个贪心策略采取在短期内看上去最优的动作，即根据$v_\pi$向前单步搜索，这样构造出的贪心策略满足策略改进的条件，所以我们知道它和原策略相比一样好，甚至更好，这种根据原策略的价值函数执行贪心算法，来构造一个更好策略的过程，我们成为策略改进<br>
确定性策略改进的方法可以很容易扩展到随机策略中，策略改进定理在随机策略的情况下也是成立的
### 3. 策略迭代
一旦一个策略$\pi$根据$v_\pi$产生了一个更好的策略$\pi'$，我们就可以通过计算$v_{\pi'}$来得到一个更优的策略$\pi''$，这样一个链式的方法就可以得到一个不断改进的策略和价值函数的序列，这种寻找最优策略的方法叫做策略迭代，注意每一次策略评估都是一个迭代计算过程，需要基于前一个策略的价值函数开始计算，这通常会使策略改进的收敛速度大幅度提高，策略迭代令人惊讶的是，它在几次迭代中就能收敛
>1. 初始化<br>
>对$s \in \mathcal{S}$，任意设定$V(s) \in \R$以及$\pi(s) \in \mathcal{A}(s)$
>
>2. 策略评估<br>
>循环：<br>
>$\quad \Delta \leftarrow 0$<br>
>$\quad$对每一个$s \in \mathcal{S}$循环：<br>
>$\quad \quad v \leftarrow V(s)$<br>
>$\quad \quad V(s) \leftarrow \sum_{s', r} p(s', r|s, \pi(s)) [r + \gamma V(s')]$<br>
>$\quad \quad \Delta \leftarrow \max(\Delta, |v - V(s)|)$<br>
>直到$\Delta < \theta$（一个决定估计精度的小正数）
>
>3. 策略改进<br>
>$policy-stable \leftarrow true$<br>
>对每一个$s \in \mathcal{S}$<br>
>$\quad old-action \leftarrow \pi(s)$<br>
>$\quad \pi(s) \leftarrow \arg\max_a \sum_{s', r} p(s', r|s, a) [r + \gamma V(s')]$<br>
>$\quad$如果$old-action \neq \pi(s)$，那么$policy-stable \leftarrow false$<br>
>如果$policy-stable$为$true$，那么停止并返回$V \approx v_*$以及$\pi \approx \pi_*$，否则跳转到策略评估
### 4. 价值迭代
有多种方式可以截断策略迭代中的策略评估步骤，并且不影响其收敛，一种特殊情况是，在一遍历后即刻停止策略评估（对每个状态进行一次更新），该算法被称为价值迭代，可将此表示为结合了策略改进与截断策略评估的简单更新公式，对任意$s \in \mathcal{S}$
$$
\begin{aligned}
v_{k+1} &\doteq \max_a \mathbb{E}[R_{t+1} + \gamma v_k(S_{t+1})|S_t = s, A_t = a] \\
&= \max_a \sum_{s', r} p(s', r|s, a)[r + \gamma v_k(s')]
\end{aligned}
$$
可以证明，对任意$v_0$，在$v_*$存在的条件下，序列$\{v_k\}$都可以收敛到$v_*$<br>
另一种理解价值迭代的方法是利用贝尔曼最优方程，仅仅是将贝尔曼最优方程变为一条更新规则<br>
考虑价值迭代如何终止，和策略评估一样，理论上价值迭代需要迭代无限次才能收敛到$v_*$，事实上，如果遍历一次中价值函数仅仅有细微的变化，那么我们就可以停止<br>
在每一次遍历中，价值迭代都有效结合了策略评估的遍历和策略改进的遍历，在每次策略改进遍历的迭代中间进行了多次策略评估遍历经常收敛的快<br>
一般来说，可以将截断策略迭代算法看作一系列的遍历序列，其中某些进行策略评估更新，而另一些则进行价值迭代更新<br>
这些算法在带折扣的有限MDP中均会收敛到最优策略
>算法参数：小阈值$\theta > 0$，用于确定估计量的精度<br>
>对于任意$s \in \mathcal{S^+}$，任意初始化$V(s)$，其中$V(终止状态) = 0$<br>
>循环：<br>
>$\quad \Delta \leftarrow 0$<br>
>$\quad$对于每一个$s \in \mathcal{S}$循环：<br>
>$\quad \quad v \leftarrow V(s)$<br>
>$\quad \quad V(s) \leftarrow \max_a \sum_{s', r} p(s', r|s, a) [r + \gamma V(s')]$<br>
>$\quad \quad \Delta \leftarrow \max(\Delta, |v - V(s)|)$<br>
>直到$\Delta < \theta$<br>
>输出一个确定的$\pi \approx \pi_*$，使得<br>
>$\pi(s) = \arg\max_a \sum_{s', r} p(s', r|s, a) [r + \gamma V(s')]$
### 5. 异步动态规划
DP方法的一个主要缺点就是它们涉及对MDP整个状态集的操作，如果状态集很大，那么即使是单次遍历也会十分昂贵<br>
异步DP算法是一类就地迭代的DP算法，其不以系统遍历状态集的形式来组织算法，这些算法使用任意可用的状态值，以任意顺序来更新状态值，在某些状态的值更新一起以前，另一个状态的值可能已经更新了好几次<br>
然而，为了正确收敛，异步算法必须要不断地更新所有状态的值：在计算某个节点后，它不能忽略任何一个状态，在选择要更新的状态方面，异步DP算法具有极大的灵活性<br>
其中一个版本就是利用价值迭代更新公式，在每一步k上都只就地更新一个状态$s_k$的值，如果$0 \leq \gamma < 1$，则只要所有状态都在序列$\{s_k\}$中出现无数次，就能保证渐进收敛到$v_*$（这个序列甚至是随机的，在非折扣分幕式情况下，有些特定顺序的更新序列可能不收敛，但这个情况相对容易避免）
### 6. 广义策略迭代
策略迭代包括两个同时进行的流程：策略评估和策略改进，两个流程交替进行，每一个流程都在另一个开始前完成，但这也不是必须的，只要两个流程持续更新到所有状态，那么最后的结果通常是相同的，即收敛到一个最优价值函数和一个最优策略<br>
广义策略迭代（GPI）指代让策略评估和策略改进相互作用的一般思路，与这两个流程的粒度与其他细节无关，几乎所有的强化学习都可以描述为GPI<br>
可以将GPI的评估和改进流程看作竞争与合作：
- 竞争是指它们朝着相反的方向前进，让策略对价值函数贪心通常会使价值函数与当前策略不匹配，而使价值函数与策略一致通常会导致策略不再贪心
- 然而，从长远来看，这两个流程会相互作用以找到一个联合解决方案：最优价值函数和一个最优策略
### 7. 动态规划的效率
动态规划算法找到最优策略的时间（最坏情况下）与动作和状态的数量是呈多项式级关系的，从这个策略意义上来说，DP算法的效率指数级优于任何直接在策略空间搜索的方法，这是因为为了找到最优策略：
- 直接搜索的方法需要穷举每一种策略
- 线性规划方法同样可以用于解决马尔可夫决策过程，且在某些例子中，它们在最坏情况下的收敛是优于DP方法，但是当状态数量较少，线性规划方法就不如DP实用
- 对那些极大规模的问题，只有动态规划算法是可行的

DP算法有时会由于维度灾难而被认为缺乏实用性，维度灾难指的是：状态的总数量经常随着状态变量的增加而指数级上升，状态集合太大的确会带来一些困难，但是这些是问题本身的困难，而非DP作为一种解法所带来的困难

对于那些有很大状态空间的问题，我们通常使用异步DP算法

## 第五章：蒙特卡洛方法<a id = "第五章"></a>

蒙特卡洛（MC）方法是一类通过采样经验（状态、动作、收益序列）来估计价值函数并寻找最优策略的实用算法。与动态规划（DP）不同，MC方法不需要完备的环境模型（即状态转移概率），只需要真实或模拟的交互经验。本章主要讨论分幕式任务中的蒙特卡洛方法，从预测（评估给定策略）到控制（寻找最优策略），并介绍同轨策略与离轨策略两种范式。

### 5.1 蒙特卡洛预测

**目标**：在给定策略 π 的情况下，用 MC 方法学习其状态价值函数 $v_π(s)$。

**基本思想**：一个状态的价值是从该状态开始的期望回报。通过对实际经验中经过该状态后产生的回报进行平均，平均值会收敛于期望值。

**两种类型**：
- **首次访问型 MC**：每幕中只使用状态 s 第一次被访问后的回报进行平均。
- **每次访问型 MC**：使用状态 s 在幕中所有被访问后的回报进行平均。

**收敛性**：
- 首次访问型：各回报独立同分布，由大数定律保证收敛。
- 每次访问型：也会二阶收敛（Singh & Sutton, 1996）。

**算法伪代码**（首次访问型 MC 预测）：
> 输入：待评估的策略 $π$<br>
> 初始化：<br>
> $\quad$ 对所有 $s∈S$，任意初始化 $V(s) \in \R$<br>
> $\quad$ 对所有 $s∈S，Returns(s) ← 空列表$<br>
> 无限循环（对每幕）：<br>
> $\quad$ 根据 π 生成一幕序列 $S_0,A_0,R_1,...,S_{T-1},A_{T-1},R_T$<br>
> $\quad G ← 0$<br>
> $\quad$ 对本幕中的每一步进行循环，$t = T-1, T-2, ..., 0$：<br>
> $\quad \quad G ← γG + R_{t+1}$<br>
> $\quad \quad $ 除非 $S_t$ 在 $S_0, S_1, ..., S_{t+1}$ 中已出现过：<br>
> $\quad \quad \quad$ 将 G 加入 $Returns(S_t)$<br>
> $\quad \quad \quad V(S_t) ← average(Returns(S_t))$

**例5.1 二十一点**：
- 规则：玩家与庄家比点数（不超过21）。玩家可要牌或停牌，庄家固定策略（≥17停牌）。
- 状态：玩家手牌和（12-21）、庄家明牌（A-10）、是否有可用A（A作11不爆）。共200状态。
- 评估策略：手牌<20时要牌，≥20停牌。通过50万局模拟得到价值函数（图5.1）。
- MC优势：无需知道概率分布，只需模拟对局即可。

**回溯图对比**：
- DP：一步回溯，考虑所有可能转移。
- MC：完整轨迹回溯，只显示实际采样到的路径，直至终止。

**MC的独立估计**：每个状态的估计独立于其他状态，无自举（不用其他状态估值来更新当前状态）。适合只关注状态子集的情况。

**例5.2 肥皂泡**（线框上的肥皂泡）：
- 问题：给定不规则线框，求肥皂膜形状（满足每点高度等于邻域平均）。
- 传统解法：网格化后迭代更新。
- MC解法：从某点随机行走至边界，边界高度的期望即该点高度。只需对感兴趣的点采样，更高效。

### 5.2 动作价值的蒙特卡洛估计

**为何需要动作价值 $q_π(s,a)$**？
- 无模型时，仅有状态价值无法选择动作（因为不知道转移概率）。
- 必须显式估计每个状态下每个动作的价值。

**方法**：
- 将对“状态”的访问改为对“状态-动作”二元组的访问。
- 首次访问型：每幕中第一次在状态 s 采取动作 a 后的回报平均。
- 每次访问型：所有访问的平均。

**试探问题**：
- 若 $π$ 是确定性的，则每个状态只会观测到一个动作，其他动作永远无法被评估。
- 需要**试探性出发假设**：每个“状态-动作”二元组作为起点的概率非零，保证无限次访问。

**练习5.3**：$q_π$ 的回溯图根节点为“状态-动作”对，轨迹包含其后所有状态-动作及终止。

### 5.3 蒙特卡洛控制

**广义策略迭代（GPI）**：交替进行策略评估（使价值函数逼近当前策略的真实值）和策略改进（根据价值函数贪心地更新策略）。

**蒙特卡洛 ES（试探性出发）**：
- 从任意策略 $π₀$ 开始，交替进行完整的策略评估（MC预测）和策略改进（贪心）。
- 策略改进：$π_{k+1}(s) \doteq \arg\max_a q_{π_k}(s,a)$。由于有动作价值函数，改进无需模型。
- 策略改进定理保证每次改进后策略更优，除非已达最优。

**去除“无限幕”假设**：
- 实际中不需要等到策略评估完全收敛，可以逐幕交替：每幕结束后立即更新该幕中访问过的“状态-动作”对的 Q 值，并更新策略。
- 算法：**蒙特卡洛 ES**（见伪代码框）。它选择所有“状态-动作”对作为起点的概率 >0，然后根据当前 π 生成一幕，反向遍历，更新回报和 Q，并贪心地更新策略。

> 初始化：<br>
> $\quad$ 对所有$s \in \mathcal{S}$, 任意初始化$\pi(s) \in \mathcal{A}$<br>
> $\quad$ 对所有$s \in \mathcal{S}, a \in \mathcal{A}$，任意初始化$Q(s, a) \in \R$<br>
> $\quad$ 对所有$s \in \mathcal{S}, Returns(s, a) \leftarrow 空列表$<br>
> 无限循环（对每幕）：<br>
> $\quad$ 选择 $\mathcal{S_0} \in \mathcal{S}$和$\mathcal{A_0} \in \mathcal{A}(S_0)$以使得所有“状态-动作”二元组的概率都$>0$<br>
> $\quad$ 从$S_0, A_0$开始根据$\pi$生成一幕序列：$S_0, A_0, R_1, ..., S_{T-1}, A_{T-1}, R_T$<br>
> $\quad G \leftarrow 0$<br>
> $\quad$ 对幕中的每一步循环，$t = T-1, T-2, ..., 0$：<br>
> $\quad \quad G \leftarrow \gamma G + R_{t+1}$<br>
> $\quad \quad$ 除非二元组$S_t, A_t$ 在 $S_0, A_0, S_1, A_1, ..., S_{t-1}, A_{t-1}$ 中已出现过：<br>
> $\quad \quad \quad$ 将$G$加入$Returns(S_t, A_t)$<br>
> $\quad \quad \quad Q(S_t, A_t) \leftarrow average(Returns(S_t, A_t))$<br>
> $\quad \quad \quad \pi(S_t) \leftarrow \arg\max_a Q(S_t, a)$

**练习5.4**：可以增量式维护平均值和计数，避免存储所有回报列表。

**收敛性**：MC ES 不会收敛到次优策略；达到最优时稳定。但严格证明仍是开放问题之一（Sitsiklis, 2002）。

**例5.3 二十一点最优策略**：使用 MC ES 得到的最优策略（图5.2）与 Thorp (1966) 的基础策略几乎一致。

### 5.4 没有试探性出发假设的蒙特卡洛控制

**问题**：试探性出发在真实环境中很难满足。需要保证智能体持续选择所有可能动作。

**两种策略**：
- **同轨策略**：生成数据的策略与待评估/改进的策略相同。
- **离轨策略**：不同（下一节）。

**同轨策略方法**：
- 策略为 **$ε$-软性**：对所有状态和动作，$π(a|s) ≥ \frac{ε}{|A(s)|}$。
- **$ε$-贪心策略**：以概率 $1-ε$ 选择贪心动作，以概率 $ε$ 均匀随机选择动作。这是最接近贪心的 $ε$-软性策略。

**策略改进**：
- 对于任意 $ε$-软性策略 $π$，根据 $q_π$ 构造的 $ε$-贪心策略 $π'$ 优于或等于 $π$。
- 证明：通过加权平均推导，最终 $v_{π'}(s) ≥ v_π(s)$。
- 等号成立当且仅当 $π$ 和 $π'$ 都是最优 $ε$-软性策略。

**同轨策略 MC 控制算法**（首次访问型，$ε$-软性）：
> 算法参数：$ε > 0$<br>
> 初始化：<br>
> $\quad π ← 一个任意 ε-软性策略$<br>
> $\quad$ 对所有 $s \in \mathcal{S}, a \in \mathcal{A}(s)$，任意初始化 $Q(s,a) \in \R$ <br>
> $\quad$ 对所有 $s \in \mathcal{S}, a \in \mathcal{A}(s), Returns(s,a) \leftarrow 空列表$<br>
> 无限循环（对每幕）：<br>
> $\quad$ 根据 $π$ 生成一幕序列：$S_0, A_0, R_1, ..., S_{T-1}, A_{T-1}, R_T$<br>
> $\quad G ← 0$<br>
> $\quad$ 对幕中的每一步循环，$t = T-1, T-2, ...,0$：<br>
> $\quad \quad G ← γG + R_{t+1}$<br>
> $\quad \quad$ 除非“状态-动作”二元组 $S_t,A_t$ 在$S_0, A_0, S_1, A_1, ..., S_{t-1}, A_{t-1}$已出现过：<br>
> $\quad \quad \quad$ 将 $G$ 加入 $Returns(S_t,A_t)$<br>
> $\quad \quad \quad Q(S_t,A_t) ← average(Returns(S_t,A_t))$<br>
> $\quad \quad \quad A* ← \arg\max_a Q(S_t,a) \quad$（有多个最大值时任意选取）<br>
> $\quad \quad \quad$ 对所有 $a \in \mathcal{A}(S_t)$：<br>
> $\quad \quad \quad \quad π(a|S_t) ← 
\begin{cases}
若 1-ε+\frac{ε}{|A(S_t)|} \quad  a=A^* \\
若\frac{ε}{|A(S_t)|} \quad a \neq A^*
\end{cases}
$

- 该算法不再需要试探性出发，但只能收敛到 $ε$-软性策略中的最优策略。

### 5.5 基于重要度采样的离轨策略

**动机**：希望学习最优策略（确定性），同时使用另一个更具试探性的策略（行动策略 $b$）来生成数据。目标策略 $π$ 与行动策略 $b$ 不同。

**覆盖假设**：若 $π(a|s)>0，则 b(a|s)>0$。即 $π$ 的所有动作在 $b$ 下也偶尔出现。

**重要度采样**：
- 给定来自分布 $b$ 的样本，估计分布 $π$ 下的期望。
- 给定起始状态$S_t$，后续的状态-动作轨迹$A_t, S_{t+1}, A_{t+1}, ..., S_T$在策略$\pi$下发生的概率是：
$$
\begin{aligned}
&Pr\{A_t, S_{t+1}, A_{t+1}, ..., S_T|S_t, A_{t: T-1} \sim \pi\} \\
&= \pi(A_t|S_t) p(S_{t+1}|S_t, A_t) \pi(A_{t+1}|S_{t+1}) ···p(S_T|S_{T-1}, A_{T-1}) \\
&= ∏_{k=t}^{T-1} \pi(A_k|S_k)p(S_{k+1}|S_k, A_k)
\end{aligned}
$$
- 重要度采样比：$$ρ_{t:T-1} \doteq \frac{∏_{k=t}^{T-1} \pi(A_k|S_k) p(S_{k+1}|S_k, A_k)}{∏_{k=t}^{T-1} b(A_k|S_k) p(S_{k+1}|S_k, A_k)} = ∏_{k=t}^{T-1} \frac{π(A_k|S_k)}{b(A_k|S_k)}$$
  - 状态转移概率 p 在分子分母中约掉，因此只需知道策略概率。
- 性质：$\mathbb{E}[ ρ_{t:T-1} G_t | S_t=s ] = v_π(s)$   
  - 从行动策略中得到的回报的期望$\mathbb{E}[G_t|S_t = s] = v_b(s)$是不准确的，所以不能用它们的平均来得到$v_\pi$

**普通重要度采样**：
- 定义所有访问过的状态$s$的时刻集合为$\mathcal{T}(s)$，而对于首次访问型方法，$\mathcal{T}(s)$只包含在幕内首次访问状态$s$的时刻，用$T(s)$来表示在时刻$t$后首次终止，用$G_t$来表示在$t$之后到达$T(t)$时的回报值，那么$\{G_t\}_{t \in \mathcal{T}(s)}$就是状态$s$对应的回报值，$\{\rho_{t:T(t)-1}\}_{t \in \mathcal{T}(s)}$是相应的重要度采样比
- 估计量：$V(s) \doteq \frac{ Σ_{t∈T(s)} ρ_{t:T(t)-1} G_t }{|T(s)|}$
- 无偏，但方差可能无穷大（尤其当轨迹有环时）。

**加权重要度采样**：
- 估计量：$V(s) = \frac{ Σ_{t∈T(s)} ρ_{t:T(t)-1} G_t }{ Σ_{t∈T(s)} ρ_{t:T(t)-1} }$
- 有偏（偏差渐近到0），方差通常较小，实践中更受欢迎。

**例5.4 二十一点离轨策略估计**：
- 行动策略：等概率要牌/停牌；目标策略：只在20/21停牌。
- 加权重要度采样比普通重要度采样收敛更快、误差更小（图5.3）。

**例5.5 无穷方差**：
- 简单单状态MDP：向左（0.9回状态，0.1终止得+1），向右（终止得0）。目标策略总是向左，行动策略等概率左右。
- 普通重要度采样的方差无穷（计算平方期望发散），估计值不收敛（图5.4）。加权重要度采样第一次得到向左动作后即得正确值1。

**练习5.6**：动作价值函数的加权重要度采样公式将 V(s) 替换为 Q(s,a)，分母求和只对访问 (s,a) 的时刻。

**练习5.7**：加权重要度采样初期可能因权值小而分母小，导致较大波动；随着分母增大，估计趋于稳定。

**练习5.8**：每次访问型方差可能仍无穷？需要具体分析。

### 5.6 增量式实现

**普通重要度采样**：可直接用第2章的增量平均，将收益替换为 $ρG$。

**加权重要度采样**：
- 维护权值和 $C_n$，更新公式：
  - 随机权重$W_k$：例如$W_k = \rho_{t: T(t)-1}$
  - $C_n$：为了能不断跟踪$V_n$的变化，必须为每一个状态维护前n个回报对应的权值的累加和
  - $V_{n+1} = V_n + \frac{W_n}{C_n} [G_n - V_n]$
  - $C_{n+1} = C_n + W_{n+1}$
- 算法框：离轨策略 MC 预测（策略评估）
> 输入：一个任意的目标策略 $π$<br>
> 初始化：对所有 $s \in \mathcal{S}, a \in \mathcal{A}(s)$：<br> 
> $\quad$ 任意初始化 $Q(s,a) \in \R$<br> 
> $\quad C(s,a) ← 0$<br>
> 无限循环（对每幕）：<br>
> $\quad b \leftarrow 任何能包括 \pi 的策略$<br>
> $\quad$ 根据 b 生成一幕序列：$S_0, A_0, R_1, ..., S_{T-1}, A_{T-1}, R_T$<br>
> $\quad G ← 0$<br>
> $\quad W ← 1$<br>
> $\quad$ 对幕中的每一步循环，$t = T-1, T-2, ..., 0$，当$W \neq 0$时：<br>
> $\quad \quad G ← γG + R_{t+1}$<br>
> $\quad \quad C(S_t,A_t) ← C(S_t,A_t) + W$<br>
> $\quad \quad Q(S_t,A_t) ← Q(S_t,A_t) + \frac{W}{C(S_t,A_t)}[G - Q(S_t,A_t)]$<br>
> $\quad \quad W ← W \frac{π(A_t|S_t)}{b(A_t|S_t)}$<br>
> $\quad \quad $若 $W=0$，退出内层循环

**练习5.9**：首次访问型 MC 的增量实现只需记录每个状态首次访问后的回报并更新。

### 5.7 离轨策略蒙特卡洛控制

**目标**：通过行动策略 $b$（软性）生成数据，学习最优目标策略 $π$（确定性贪心）。

**算法**：离轨策略 MC 控制
>初始化，对所有 $s \in \mathcal{S},a \in \mathcal{A}(s)$：<br> 
>$\quad$ 初始化 $Q(s,a) \in \R$（任意值）<br>
>$\quad C(s,a) ← 0$<br>
>$\quad π(s) ← \arg\max_a Q(s,a)$（出现平分的情况下选取方法应保持一致）<br>
>无限循环（对每幕）：<br>
>$\quad b ← 任意软性策略（如 ε-贪心）$<br>
>$\quad$ 根据 $b$ 生成一幕数据：$S_0, A_0, R_1, ..., S_{T-1}, A_{T-1}, R_T$<br>
>$\quad G ← 0$<br>
>$\quad W ← 1$<br>
>$\quad$ 对幕中的每一时刻循环 $t = T-1, T-2, ..., 0$：<br>
>$\quad \quad G ← γG + R_{t+1}$<br>
>$\quad \quad C(S_t,A_t) ← C(S_t,A_t) + W$<br>
>$\quad \quad Q(S_t,A_t) ← Q(S_t,A_t) + \frac{W}{C(S_t,A_t)} [G - Q(S_t,A_t)]$<br>
>$\quad \quad π(S_t) ← \arg\max_a Q(S_t,a)$（出现平分的情况下选取方法应保持一致）<br>
>$\quad \quad$ 如果 $A_t ≠ π(S_t)$：那么退出内层循环（处理下一幕数据）<br>
>$\quad \quad W ← W \frac{1}{b(A_t|S_t)}$

**解释**：$W $的更新只用 $1/b$，因为 $π(A_t|S_t)=1$（贪心动作）若 $A_t$ 是贪心动作；否则循环提前退出。

**问题**：从尾部开始学习，若早期非贪心动作多，学习慢。可使用时序差分学习（第6章）缓解。

**练习5.11**：正确性在于当 $A_t=π(S_t)$ 时，$π(A_t|S_t)=1$，故$重要度比 = 1/b$。

**练习5.12 赛道问题**：编程练习，使用 MC 控制求解最优赛车轨迹。

### 5.8 * 折扣敏感的重要度采样

**动机**：当折扣 γ 显著小于1时，回报主要由早期收益决定，但重要度采样比包含整个轨迹的许多因子，引入不必要的高方差。

**思想**：
- 将折扣视为“部分终止”的概率。定义平价部分回报 $$\bar{G}_{t:h} \doteq R_{t+1}+...+R_h, \quad 0 \leq t < h \leq T$$（无折扣）。
  - 对于任何$\gamma \in [0, 1)$，我们可以把回报$G_0$看作在一步内，以$1 - \gamma$的程度部分终止，产生的回报仅仅是首次收益$R_1$，然后再在两步后以$(1-\gamma) \gamma$的程度部分终止，产生$R_1+R_2$的回报，以此类推
  - “平价”表示没有折扣
  - “部分”表示这些回报不会一直延续到终止，而在$h$处停止，$h$称为视界（$T$是幕终止的时间）
  - 传统的全回报$G_t$可被看作上述平价部分回报的总和
- 全回报可分解为：
$$G_t = (1-γ)∑_{h=t+1}^{T-1} γ^{h-t-1} \bar{G}_{t:h} + γ^{T-t-1} \bar{G}_{t:T}$$

**折扣敏感重要度采样**：
- 普通形式：$$V(s) = \frac{∑_{t \in \mathcal{T}(s)} ( (1-γ)∑_{h=t+1}^{T(t)-1} γ^{h-t-1} ρ_{t:h-1} \bar{G}_{t:h} + γ^{T(t)-t-1} ρ_{t:T(t)-1} \bar{G}_{t:T(t)} )}{|\mathcal{T}(s)|}$$
- 加权形式：$$V(s) = \frac{∑_{t \in \mathcal{T}(s)} ( (1-γ)∑_{h=t+1}^{T(t)-1} γ^{h-t-1} ρ_{t:h-1} \bar{G}_{t:h} + γ^{T(t)-t-1} ρ_{t:T(t)-1} \bar{G}_{t:T(t)} )}{∑_{t \in \mathcal{T}(s)} ( (1-γ)∑_{h=t+1}^{T(t)-1} γ^{h-t-1} ρ_{t:h-1} + γ^{T(t)-t-1} ρ_{t:T(t)-1})}$$
- 方差更低，尤其当 $γ<1$ 时。当$\gamma = 1$时没有任何影响

### 5.9 * 每次决策型重要度采样

**思想**：将回报拆解为每步收益的加权和，重要度采样比可以分步应用，因为后续因子的期望为1。

推导：
$\mathbb{E}[ρ_{t:T-1} R_{t+1}] = \mathbb{E}[ρ_{t:t} R_{t+1}]$  （因为后续比率的期望为1）
类似地，$\mathbb{E}[ρ_{t:T-1} R_{t+k}] = \mathbb{E}[ρ_{t:t+k-1} R_{t+k}]$

定义 $$\tilde{G_t} = ρ_{t:t} R_{t+1} + γ ρ_{t:t+1} R_{t+2} + ... + γ^{T-t-1} ρ_{t:T-1} R_T$$
则 $E[\tilde{G}_t] = E[ρ_{t:T-1} G_t]$，且方差更小。

**普通重要度采样**可用 $\tilde{G}_t$ 替代 $ρG_t$ 得到无偏且低方差估计（式5.15）$$V(s) \doteq \frac{\sum_{t \in \mathcal{T}(s)}\tilde{G_t}}{|\mathcal{T}(s)|}$$
加权重要度采样的每次决策型版本尚未知是否一致。

**练习5.13**：推导需利用独立性和期望为1的性质。

**练习5.14**：将截断加权平均估计器（式5.10）推广到动作价值函数。
