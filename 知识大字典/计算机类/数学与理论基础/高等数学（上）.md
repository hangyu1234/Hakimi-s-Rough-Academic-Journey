## 第五章：微分方程<a id = "第五章"></a>
### 5.1 微分方程的基本概念<a id = "5.1"></a>

微分方程是描述未知函数及其导数之间关系的方程，是数学建模和科学计算的核心工具。本节介绍微分方程的定义、阶数、线性与非线性、齐次与非齐次、解、通解、特解、初始条件以及积分曲线等基本概念。

#### 一、微分方程的定义

##### 1.1 常微分方程与偏微分方程
- **常微分方程**（Ordinary Differential Equation, ODE）：未知函数是一元函数，方程中包含未知函数及其导数。例如：
  $$ \frac{dy}{dx} = 2x + y, \quad \frac{d^2y}{dx^2} + 3\frac{dy}{dx} + 2y = e^x $$
- **偏微分方程**（Partial Differential Equation, PDE）：未知函数是多元函数，方程中包含偏导数。例如热传导方程：
  $$ \frac{\partial u}{\partial t} = \alpha \frac{\partial^2 u}{\partial x^2} $$
本课程主要讨论常微分方程。

##### 1.2 微分方程的阶（Order）
微分方程的**阶**是指方程中出现的未知函数导数的最高阶数。
- 一阶：$y' + y = 0$
- 二阶：$y'' - 3y' + 2y = 0$
- $n$ 阶：$F(x, y, y', \dots, y^{(n)}) = 0$

##### 1.3 线性与非线性
若方程中未知函数及其各阶导数均为一次（且无乘积项、复合函数等），则称为**线性微分方程**；否则为**非线性**。
- 线性一阶：$y' + p(x)y = q(x)$
- 线性二阶：$y'' + p(x)y' + q(x)y = r(x)$
- 非线性：$y' = y^2$，$y'' + \sin y = 0$

##### 1.4 齐次与非齐次
对于线性微分方程，若方程中不含仅依赖于自变量的项（即自由项为零），则称为**齐次**；否则称为**非齐次**。
- 齐次：$y'' + p(x)y' + q(x)y = 0$
- 非齐次：$y'' + p(x)y' + q(x)y = f(x)$，其中 $f(x) \not\equiv 0$

#### 二、微分方程的解

##### 2.1 解的定义
若函数 $y = \varphi(x)$ 代入方程后，使方程成为恒等式（在某个区间 $I$ 上），则称 $\varphi(x)$ 是方程在该区间上的一个**解**。

##### 2.2 通解与特解
- **通解**：含有 $n$ 个相互独立的任意常数（$n$ 为方程的阶）的解。例如一阶方程的通解为 $y = \varphi(x, C)$，二阶为 $y = \varphi(x, C_1, C_2)$。
- **特解**：通过确定通解中的任意常数而得到的具体解。通常由**初始条件**（见后）确定。

##### 2.3 初始条件（初值条件）
初始条件用于从通解中确定特定常数，反映系统在初始时刻的状态。
- 一阶方程：给出 $y(x_0) = y_0$
- 二阶方程：给出 $y(x_0) = y_0$ 和 $y'(x_0) = y_0'$

##### 2.4 初值问题（柯西问题）
求微分方程满足给定初始条件的特解的问题，称为**初值问题**。例如：
$$ \begin{cases} y' = 2x + y \\ y(0) = 1 \end{cases} $$

#### 三、积分曲线

##### 3.1 几何意义
微分方程的解 $y = y(x)$ 在平面上表示一条曲线，称为**积分曲线**。一阶微分方程 $y' = f(x, y)$ 在每一点 $(x, y)$ 处给出了切线的斜率，因此其积分曲线族在平面上形成一种方向场（斜率场）。

##### 3.2 方向场（斜率场）
对于一阶方程 $y' = f(x, y)$，可以在平面网格点上画出短线段，其斜率为 $f(x, y)$，这些线段构成方向场。积分曲线与方向场处处相切。

#### 四、典型例题

##### 例1：判断微分方程的阶、线性性
判断下列方程的类型：
1. $y'' - 2x y' + \cos y = e^x$
   - 阶：二阶（最高导数为 $y''$）
   - 非线性：因为含有 $\cos y$（不是 $y$ 的一次项）
2. $x^2 y'' + x y' + (x^2 - 1)y = 0$
   - 阶：二阶
   - 线性：所有项均为 $y, y', y''$ 的一次项，且无乘积；系数仅依赖于 $x$。
   - 齐次：右端为零，所以是齐次线性方程。

##### 例2：验证函数是否为解
验证 $y = e^{2x}$ 是否为方程 $y'' - 4y = 0$ 的解。
解：$y' = 2e^{2x}$，$y'' = 4e^{2x}$，代入得 $4e^{2x} - 4e^{2x} = 0$，恒成立，故是解（特解）。通解为 $y = C_1 e^{2x} + C_2 e^{-2x}$。

##### 例3：求初值问题的特解
已知一阶方程 $y' = 2x$ 的通解为 $y = x^2 + C$，求满足 $y(0)=3$ 的特解。
解：代入 $x=0$，$y=3$ 得 $3 = 0 + C$，所以 $C=3$，特解为 $y = x^2 + 3$。

#### 五、小结

微分方程的基本概念是后续学习各种解法的基础。你需要掌握：
1. 微分方程的定义及阶的判定。
2. 线性与非线性、齐次与非齐次的区别。
3. 解、通解、特解的含义。
4. 初始条件的含义及初值问题的提法。
5. 积分曲线与方向场的几何直观。

### 5.2 一阶微分方程<a id = "5.2"></a>

一阶微分方程是只含未知函数的一阶导数的方程，一般形式为 $F(x, y, y') = 0$ 或显式 $y' = f(x, y)$。求解一阶微分方程没有统一的方法，需要根据方程类型选择合适的技巧。本节介绍几种常见类型：可分离变量方程、齐次方程、一阶线性微分方程、伯努利方程、全微分方程（恰当方程）以及可降阶的高阶方程。

#### 一、可分离变量方程

##### 1.1 形式
$$ \frac{dy}{dx} = g(x)h(y) \quad \text{或} \quad M(x)\,\mathrm{d}x + N(y)\,\mathrm{d}y = 0 $$
其中 $M(x)$ 仅含 $x$，$N(y)$ 仅含 $y$。

##### 1.2 解法
将变量分离到等式两边：
$$ \frac{1}{h(y)}\,\mathrm{d}y = g(x)\,\mathrm{d}x $$
两边积分：
$$ \int \frac{1}{h(y)}\,\mathrm{d}y = \int g(x)\,\mathrm{d}x + C $$
求出积分后，得到隐式通解（有时可显化）。

##### 1.3 示例
解方程 $y' = \frac{x}{y}$。
解：分离变量：$y\,\mathrm{d}y = x\,\mathrm{d}x$，积分：$\frac{1}{2}y^2 = \frac{1}{2}x^2 + C$，故 $y^2 - x^2 = C_1$（$C_1=2C$）。

#### 二、齐次方程

##### 2.1 形式
$$ y' = f\left(\frac{y}{x}\right) $$
即右端可表示为 $\frac{y}{x}$ 的函数。

##### 2.2 解法
令 $u = \frac{y}{x}$，则 $y = ux$，$y' = u + x u'$。代入原方程得：
$$ u + x u' = f(u) \quad \Rightarrow \quad x \frac{du}{dx} = f(u) - u $$
这是可分离变量方程（变量 $u$ 和 $x$），分离后积分即可。

##### 2.3 示例
解方程 $y' = \frac{x + y}{x - y}$。
解：改写 $y' = \frac{1 + y/x}{1 - y/x}$，令 $u = y/x$，得 $u + x u' = \frac{1+u}{1-u}$，即 $x u' = \frac{1+u}{1-u} - u = \frac{1+u - u(1-u)}{1-u} = \frac{1+u - u + u^2}{1-u} = \frac{1+u^2}{1-u}$。
分离变量：$\frac{1-u}{1+u^2}\,\mathrm{d}u = \frac{\mathrm{d}x}{x}$，积分得 $\arctan u - \frac{1}{2}\ln(1+u^2) = \ln|x| + C$，代回 $u = y/x$ 得隐式解。

#### 三、一阶线性微分方程

##### 3.1 形式
$$ y' + p(x)y = q(x) $$
其中 $p(x), q(x)$ 是已知连续函数。若 $q(x) \equiv 0$，则为齐次线性方程；否则为非齐次。

##### 3.2 解法：常数变易法或积分因子法
- **积分因子法**：乘以积分因子 $\mu(x) = e^{\int p(x)\,\mathrm{d}x}$，则左边变为 $(\mu y)' = \mu q$，两边积分得：
  $$ \mu(x) y = \int \mu(x) q(x)\,\mathrm{d}x + C $$
  因此通解为：
  $$ y = e^{-\int p\,\mathrm{d}x} \left( \int q e^{\int p\,\mathrm{d}x}\,\mathrm{d}x + C \right) $$
- **常数变易法**：先解齐次方程 $y' + p y = 0$ 得 $y_h = Ce^{-\int p\,\mathrm{d}x}$；再将常数 $C$ 视为函数 $u(x)$，代入非齐次方程解出 $u$，得到相同公式。

##### 3.3 示例
解 $y' + 2xy = x$。
解：$p(x)=2x$，$\int p\,\mathrm{d}x = x^2$，积分因子 $\mu = e^{x^2}$。两边乘 $\mu$：$(e^{x^2}y)' = x e^{x^2}$，积分得 $e^{x^2}y = \frac{1}{2} e^{x^2} + C$，故 $y = \frac{1}{2} + Ce^{-x^2}$。

#### 四、伯努利方程

##### 4.1 形式
$$ y' + p(x)y = q(x)y^n \quad (n \neq 0, 1) $$
当 $n=0$ 或 $1$ 时即为线性方程。

##### 4.2 解法
令 $u = y^{1-n}$，则 $u' = (1-n)y^{-n}y'$。将原方程两边乘以 $(1-n)y^{-n}$ 得：
$$ (1-n)y^{-n}y' + (1-n)p(x)y^{1-n} = (1-n)q(x) $$
即 $u' + (1-n)p(x)u = (1-n)q(x)$，转化为一阶线性方程关于 $u$。

##### 4.3 示例
解 $y' + \frac{y}{x} = x y^2$。
解：$n=2$，令 $u = y^{-1}$，则 $u' = -y^{-2}y'$。原式乘以 $-y^{-2}$：$-y^{-2}y' - \frac{1}{x}y^{-1} = -x$，即 $u' - \frac{1}{x}u = -x$。这是一阶线性，积分因子 $\mu = e^{-\int \frac{1}{x}\mathrm{d}x} = e^{-\ln|x|} = \frac{1}{x}$（取正）。两边乘 $\frac{1}{x}$：$\frac{1}{x}u' - \frac{1}{x^2}u = -1$，即 $(\frac{u}{x})' = -1$，积分得 $\frac{u}{x} = -x + C$，所以 $u = -x^2 + Cx$，代回 $u = 1/y$ 得 $y = \frac{1}{Cx - x^2}$。

#### 五、全微分方程（恰当方程）

##### 5.1 形式
$$ M(x,y)\,\mathrm{d}x + N(x,y)\,\mathrm{d}y = 0 $$
其中 $\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}$（在单连通区域内），则方程是**恰当方程**，即存在 $u(x,y)$ 使得 $\mathrm{d}u = M\,\mathrm{d}x + N\,\mathrm{d}y$。

##### 5.2 解法
- 验证恰当性：$\frac{\partial M}{\partial y} \overset{?}{=} \frac{\partial N}{\partial x}$。
- 求原函数 $u(x,y)$：$u = \int M\,\mathrm{d}x + \varphi(y)$，利用 $\frac{\partial u}{\partial y} = N$ 确定 $\varphi(y)$（或先对 $y$ 积分）。
- 通解为 $u(x,y) = C$。

##### 5.3 积分因子
若方程不是恰当的，但存在函数 $\mu(x,y)$ 使得 $\mu M\,\mathrm{d}x + \mu N\,\mathrm{d}y = 0$ 成为恰当方程，则 $\mu$ 称为**积分因子**。常见情况：
- 若 $\frac{1}{N}\left(\frac{\partial M}{\partial y} - \frac{\partial N}{\partial x}\right)$ 仅与 $x$ 有关，则 $\mu = e^{\int \frac{1}{N}(\frac{\partial M}{\partial y} - \frac{\partial N}{\partial x})\,\mathrm{d}x}$。
- 若 $\frac{1}{M}\left(\frac{\partial N}{\partial x} - \frac{\partial M}{\partial y}\right)$ 仅与 $y$ 有关，则 $\mu = e^{\int \frac{1}{M}(\frac{\partial N}{\partial x} - \frac{\partial M}{\partial y})\,\mathrm{d}y}$。

##### 5.4 示例
解方程 $(2x + y)\,\mathrm{d}x + (x + 2y)\,\mathrm{d}y = 0$。
解：$M=2x+y$，$N=x+2y$，$\frac{\partial M}{\partial y}=1$，$\frac{\partial N}{\partial x}=1$，恰当。求 $u$：$u = \int M\,\mathrm{d}x = x^2 + xy + \varphi(y)$，$\frac{\partial u}{\partial y} = x + \varphi'(y) = N = x+2y$，得 $\varphi'(y)=2y$，$\varphi(y)=y^2$。通解 $x^2 + xy + y^2 = C$。

#### 六、可降阶的高阶方程（将高阶方程化为一阶）

某些高阶微分方程可以通过变量替换降阶，成为一阶方程。

##### 6.1 类型一：$y^{(n)} = f(x)$
直接逐次积分 $n$ 次即可得到通解，含有 $n$ 个任意常数。

##### 6.2 类型二：$y'' = f(x, y')$（不显含 $y$）
令 $p = y'$，则 $y'' = p'$，方程化为 $p' = f(x, p)$，这是一阶方程，解出 $p = \varphi(x, C_1)$，再积分得 $y = \int \varphi(x, C_1)\,\mathrm{d}x + C_2$。

##### 6.3 类型三：$y'' = f(y, y')$（不显含 $x$）
令 $p = y'$，并将 $y''$ 表示为 $p \frac{dp}{dy}$（因为 $y'' = \frac{dp}{dx} = \frac{dp}{dy} \frac{dy}{dx} = p \frac{dp}{dy}$）。方程化为 $p \frac{dp}{dy} = f(y, p)$，这是一阶方程（自变量 $y$，未知函数 $p$）。解出 $p = \varphi(y, C_1)$，再由 $\frac{dy}{dx} = \varphi(y, C_1)$ 分离变量积分得 $x = \int \frac{dy}{\varphi(y, C_1)} + C_2$。

##### 6.4 示例
1. $y'' = x + \sin x$（类型一）直接积分两次得 $y = \frac{x^3}{6} - \sin x + C_1 x + C_2$。
2. $y'' = 2x(y')^2$（不显含 $y$）：令 $p=y'$，则 $p' = 2x p^2$，分离变量 $\frac{dp}{p^2} = 2x\,dx$，积分得 $-\frac{1}{p} = x^2 + C_1$，故 $p = -\frac{1}{x^2+C_1}$，再积分得 $y = -\int \frac{dx}{x^2+C_1} = -\frac{1}{\sqrt{C_1}}\arctan\frac{x}{\sqrt{C_1}} + C_2$（当 $C_1>0$）等形式。
3. $y y'' = (y')^2$（不显含 $x$）：令 $p=y'$，则 $y p \frac{dp}{dy} = p^2$，若 $p \neq 0$，则 $y \frac{dp}{dy} = p$，分离变量得 $\frac{dp}{p} = \frac{dy}{y}$，积分得 $\ln|p| = \ln|y| + C_1'$，即 $p = C_1 y$。于是 $\frac{dy}{dx} = C_1 y$，解得 $y = C_2 e^{C_1 x}$。另 $p=0$ 给出 $y$ 常数（包含在 $C_2=0$ 时）。

#### 七、典型例题

##### 例1：解 $y' = \frac{y^2 + x^2}{xy}$
解：可化为 $y' = \frac{x}{y} + \frac{y}{x}$，令 $u = y/x$，则 $y = ux$，$y' = u + x u' = \frac{1}{u} + u$，得 $x u' = \frac{1}{u}$，分离变量 $u\,\mathrm{d}u = \frac{\mathrm{d}x}{x}$，积分 $\frac{1}{2}u^2 = \ln|x| + C$，故 $u^2 = 2\ln|x| + C_1$，代回 $y = x u$ 得 $y^2 = x^2 (2\ln|x| + C_1)$。

##### 例2：解伯努利方程 $y' - y = xy^3$
解：$n=3$，令 $u = y^{-2}$，则 $u' = -2y^{-3}y'$。原方程乘以 $-2y^{-3}$：$-2y^{-3}y' + 2y^{-2} = -2x$，即 $u' + 2u = -2x$。线性方程，积分因子 $\mu = e^{2x}$，$(u e^{2x})' = -2x e^{2x}$，积分得 $u e^{2x} = - \int 2x e^{2x} dx = -(x e^{2x} - \frac{1}{2}e^{2x}) + C$，故 $u = -x + \frac{1}{2} + C e^{-2x}$，即 $y^{-2} = \frac{1}{2} - x + C e^{-2x}$。

#### 八、小结

一阶微分方程的解法多样，关键在于识别类型并选用恰当方法。你需要掌握：
1. 可分离变量方程：分离后直接积分。
2. 齐次方程：令 $u = y/x$ 化为可分离变量。
3. 一阶线性方程：使用积分因子公式或常数变易法。
4. 伯努利方程：代换 $u = y^{1-n}$ 化为线性。
5. 全微分方程：验证恰当性，求原函数；对于非恰当方程，寻找积分因子。
6. 可降阶的高阶方程：通过适当代换（$p = y'$，注意 $y'' = p\frac{dp}{dy}$）降为一阶。

熟练运用这些方法，可以解决大多数常见的一阶微分方程问题。

### 5.3 二阶及高阶线性微分方程<a id = "5.3"></a>

线性微分方程是微分方程的重要分支，其理论成熟，求解方法系统。本节主要介绍二阶及高阶线性微分方程的解的结构、常系数齐次方程的解法（特征方程法）、非齐次方程的解法（待定系数法、常数变易法），以及欧拉方程和高阶方程的推广。

#### 一、线性微分方程解的结构

##### 1.1 二阶线性微分方程的一般形式
$$ y'' + p(x)y' + q(x)y = f(x) $$
若 $f(x) \equiv 0$，则称为**齐次线性方程**；否则为**非齐次线性方程**。

##### 1.2 齐次线性方程解的结构（叠加原理）
设 $y_1(x)$ 和 $y_2(x)$ 是齐次方程的两个解，则它们的任意线性组合 $C_1 y_1 + C_2 y_2$ 也是解。若 $y_1$ 与 $y_2$ 线性无关（即 $y_1/y_2 \neq$ 常数），则它们构成齐次方程的一个**基本解组**，通解为：
$$ y_h = C_1 y_1 + C_2 y_2 $$

##### 1.3 非齐次线性方程解的结构
设 $y_p$ 是非齐次方程的一个特解，$y_h$ 是对应齐次方程的通解，则非齐次方程的通解为：
$$ y = y_h + y_p $$

##### 1.4 刘维尔公式（Abel 公式）
对于 $y'' + p(x)y' + q(x)y = 0$，两个线性无关解的朗斯基行列式满足：
$$ W(x) = W(x_0) e^{-\int p(x)\,dx} $$

#### 二、二阶常系数齐次线性微分方程

##### 2.1 形式
$$ y'' + a y' + b y = 0 \quad (a,b \text{ 为常数}) $$

##### 2.2 特征方程
设解为 $y = e^{rx}$，代入得 $r^2 + a r + b = 0$，称为**特征方程**。根据特征根的不同情况，通解形式如下：

###### 2.2.1 两个不等实根 $r_1, r_2$
通解为：
$$ y = C_1 e^{r_1 x} + C_2 e^{r_2 x} $$

###### 2.2.2 二重实根 $r$（$\Delta = 0$）
通解为：
$$ y = (C_1 + C_2 x) e^{r x} $$

###### 2.2.3 一对共轭复根 $r = \alpha \pm i\beta$（$\beta \neq 0$）
通解为：
$$ y = e^{\alpha x}(C_1 \cos \beta x + C_2 \sin \beta x) $$

##### 2.3 示例
- $y'' - 3y' + 2y = 0$：特征方程 $r^2 - 3r + 2 = 0$，根 $r_1=1, r_2=2$，通解 $y = C_1 e^{x} + C_2 e^{2x}$。
- $y'' + 2y' + 1 = 0$：$r^2 + 2r + 1 = (r+1)^2 = 0$，$r=-1$（二重），通解 $y = (C_1 + C_2 x)e^{-x}$。
- $y'' + 4y = 0$：$r^2 + 4 = 0$，$r = \pm 2i$，$\alpha=0,\beta=2$，通解 $y = C_1 \cos 2x + C_2 \sin 2x$。

#### 三、二阶常系数非齐次线性微分方程

##### 3.1 形式
$$ y'' + a y' + b y = f(x) $$

##### 3.2 待定系数法（适用于 $f(x)$ 为多项式、指数、三角函数及其组合）

###### 3.2.1 基本形式及特解设定
设 $f(x) = e^{\lambda x} P_m(x)$，其中 $P_m(x)$ 是 $m$ 次多项式。则特解形式设为：
$$ y_p = x^k e^{\lambda x} Q_m(x) $$
其中 $Q_m(x)$ 是与 $P_m(x)$ 同次的多项式（系数待定），$k$ 是特征根 $\lambda$ 的重数：
- 若 $\lambda$ 不是特征根，$k=0$；
- 若 $\lambda$ 是单特征根，$k=1$；
- 若 $\lambda$ 是重特征根，$k=2$。

###### 3.2.2 三角函数形式
若 $f(x) = e^{\alpha x}(P_m(x)\cos\beta x + Q_n(x)\sin\beta x)$，则特解形式设为：
$$ y_p = x^k e^{\alpha x}(R_M(x)\cos\beta x + S_M(x)\sin\beta x) $$
其中 $M = \max(m,n)$，$k$ 是 $\alpha + i\beta$ 作为特征根的重数（通常0或1）。

##### 3.3 常数变易法（适用于任意 $f(x)$，但计算繁琐）
已知齐次通解 $y_h = C_1 y_1 + C_2 y_2$，设 $y_p = u_1(x) y_1 + u_2(x) y_2$，代入原方程，利用约束条件解出 $u_1', u_2'$ 并积分。

##### 3.4 示例
解 $y'' - 2y' - 3y = e^{4x}$。
- 特征方程 $r^2 - 2r - 3 = 0$，根 $r_1=3, r_2=-1$，齐次通解 $y_h = C_1 e^{3x} + C_2 e^{-x}$。
- $f(x)=e^{4x}$，$\lambda=4$ 不是特征根，设 $y_p = A e^{4x}$。代入得 $(16A - 8A - 3A)e^{4x} = 5A e^{4x} = e^{4x}$，所以 $A=1/5$。非齐次通解 $y = C_1 e^{3x} + C_2 e^{-x} + \frac{1}{5}e^{4x}$。

解 $y'' - 2y' + y = e^{x}$。
- 特征方程 $r^2 - 2r + 1 = (r-1)^2=0$，二重根 $r=1$，齐次通解 $y_h = (C_1 + C_2 x)e^{x}$。
- $f(x)=e^{x}$，$\lambda=1$ 是二重特征根，设 $y_p = A x^2 e^{x}$。计算 $y_p' = A(2x + x^2)e^{x}$，$y_p'' = A(2 + 4x + x^2)e^{x}$，代入得 $A(2 + 4x + x^2 - 2(2x+x^2) + x^2)e^{x} = 2A e^{x} = e^{x}$，得 $A=1/2$。通解 $y = (C_1 + C_2 x)e^{x} + \frac{1}{2}x^2 e^{x}$。

#### 四、欧拉方程

##### 4.1 形式
$$ x^2 y'' + a x y' + b y = 0 \quad (x>0) $$
其中 $a,b$ 为常数。通过变量代换 $x = e^t$（或 $t = \ln x$）可化为常系数线性方程。

##### 4.2 解法
令 $x = e^t$，则 $\frac{dy}{dx} = \frac{1}{x}\frac{dy}{dt}$，$\frac{d^2y}{dx^2} = \frac{1}{x^2}\left(\frac{d^2y}{dt^2} - \frac{dy}{dt}\right)$。代入原方程得：
$$ \frac{d^2y}{dt^2} + (a-1)\frac{dy}{dt} + b y = 0 $$
这是关于 $t$ 的常系数方程。解出 $y(t)$ 后，代回 $t = \ln x$。

##### 4.3 直接设解 $y = x^r$
也可直接设 $y = x^r$ 代入，得特征方程：
$$ r(r-1) + a r + b = 0 \quad \Rightarrow \quad r^2 + (a-1)r + b = 0 $$
与上述变换后的特征方程一致。根据根的情况写出通解（$x>0$）：
- 两个不等实根 $r_1, r_2$：$y = C_1 x^{r_1} + C_2 x^{r_2}$
- 二重实根 $r$：$y = (C_1 + C_2 \ln x) x^r$
- 共轭复根 $r = \alpha \pm i\beta$：$y = x^{\alpha}(C_1 \cos(\beta \ln x) + C_2 \sin(\beta \ln x))$

##### 4.4 示例
解 $x^2 y'' + x y' + y = 0$。
设 $y = x^r$，代入得 $r(r-1) + r + 1 = r^2 + 1 = 0$，$r = \pm i$。通解 $y = C_1 \cos(\ln x) + C_2 \sin(\ln x)$。

#### 五、高阶常系数线性微分方程

##### 5.1 形式
$$ y^{(n)} + a_{n-1} y^{(n-1)} + \dots + a_1 y' + a_0 y = f(x) $$
其中 $a_i$ 为常数。

##### 5.2 齐次方程解法
特征方程为：
$$ r^n + a_{n-1} r^{n-1} + \dots + a_1 r + a_0 = 0 $$
根据特征根写出通解：
- 单实根 $r$：对应项 $C e^{rx}$
- $k$ 重实根 $r$：对应项 $(C_1 + C_2 x + \dots + C_k x^{k-1}) e^{rx}$
- 单对共轭复根 $\alpha \pm i\beta$：对应项 $e^{\alpha x}(C_1 \cos\beta x + C_2 \sin\beta x)$
- 重共轭复根（$k$ 重）：对应项 $e^{\alpha x}\big[(C_{1}+C_{2}x+...+C_{k}x^{k-1})\cos\beta x + (D_{1}+D_{2}x+...+D_{k}x^{k-1})\sin\beta x\big]$

##### 5.3 非齐次方程解法
与二阶类似，使用待定系数法（适用于 $f(x)$ 为指数、多项式、三角函数及其乘积）或常数变易法（理论上可行，但计算复杂）。

##### 5.4 示例
解 $y''' - 2y'' + y' = 0$。
特征方程 $r^3 - 2r^2 + r = r(r^2 - 2r + 1) = r(r-1)^2 = 0$，根 $r_1=0$（单根），$r_2=1$（二重根）。通解 $y = C_1 + (C_2 + C_3 x)e^{x}$。

#### 六、典型例题

##### 例1：求初值问题
解 $y'' - 2y' + 2y = 0$，$y(0)=1$，$y'(0)=0$。
特征方程 $r^2 - 2r + 2 = 0$，根 $r = 1 \pm i$，通解 $y = e^{x}(C_1 \cos x + C_2 \sin x)$。代入初值：$y(0)=C_1=1$，$y'(0)=e^{x}((C_1+C_2)\cos x + (C_2-C_1)\sin x)$ 在 $x=0$ 得 $C_1+C_2=0$，故 $C_2=-1$。特解 $y = e^{x}(\cos x - \sin x)$。

##### 例2：用待定系数法求特解
求 $y'' + y = \sin x$ 的特解。
特征根 $r = \pm i$，齐次解 $y_h = C_1 \cos x + C_2 \sin x$。$f(x)=\sin x = e^{0x}\sin 1x$，$\alpha=0,\beta=1$，而 $\alpha+i\beta=i$ 是特征根，因此特解设为 $y_p = x(A \cos x + B \sin x)$。代入计算得 $A=0, B=-1/2$，所以 $y_p = -\frac{x}{2}\cos x$。

#### 七、小结

二阶及高阶线性微分方程是工程数学的核心内容。你需要掌握：
1. 线性微分方程解的结构（叠加原理、齐次通解+非齐次特解）。
2. 常系数齐次方程的解法：写出特征方程，根据根的情况写出通解。
3. 常系数非齐次方程的待定系数法：根据 $f(x)$ 形式设特解，注意与齐次解重复时乘以 $x^k$。
4. 欧拉方程的解法：设 $y=x^r$ 或变量代换 $x=e^t$ 化为常系数。
5. 高阶常系数方程的推广（特征根的重数处理）。

### 5.4 微分方程组简介<a id = "5.4"></a>

微分方程组是描述多个未知函数及其导数之间关系的方程组，广泛应用于力学、电路、生物种群、经济等领域。本节介绍微分方程组的基本概念、线性微分方程组的矩阵表示、常系数线性微分方程组的解法（特征值与特征向量法），以及解的结构。

#### 一、微分方程组的基本概念

##### 1.1 定义
含有多个未知函数及其导数的方程组称为**微分方程组**。例如：
$$ \begin{cases}
\frac{dx}{dt} = ax + by \\[4pt]
\frac{dy}{dt} = cx + dy
\end{cases} $$
其中 $x(t), y(t)$ 是未知函数，$t$ 是自变量。未知函数个数称为方程组的**维数**。

##### 1.2 阶数
方程组中未知函数导数的最高阶数称为方程组的**阶**。上述例子是一阶微分方程组（只含一阶导数）。

##### 1.3 线性与非线性
若所有方程关于未知函数及其导数都是线性的（即没有乘积项、幂次、复合函数等），则称为**线性微分方程组**；否则为非线性。通常，一阶线性微分方程组可写成：
$$ \begin{cases}
x_1' = a_{11}(t)x_1 + a_{12}(t)x_2 + \cdots + a_{1n}(t)x_n + f_1(t) \\
x_2' = a_{21}(t)x_1 + a_{22}(t)x_2 + \cdots + a_{2n}(t)x_n + f_2(t) \\
\vdots \\
x_n' = a_{n1}(t)x_1 + a_{n2}(t)x_2 + \cdots + a_{nn}(t)x_n + f_n(t)
\end{cases} $$
若 $f_i(t) \equiv 0$，则为**齐次线性方程组**；否则为**非齐次**。

#### 二、矩阵表示

将未知函数、系数、非齐次项写成矩阵形式，极大简化表达。

##### 2.1 向量与矩阵
令
$$ \mathbf{x}(t) = \begin{pmatrix} x_1(t) \\ x_2(t) \\ \vdots \\ x_n(t) \end{pmatrix}, \quad 
A(t) = \begin{pmatrix}
a_{11}(t) & a_{12}(t) & \cdots & a_{1n}(t) \\
a_{21}(t) & a_{22}(t) & \cdots & a_{2n}(t) \\
\vdots & \vdots & \ddots & \vdots \\
a_{n1}(t) & a_{n2}(t) & \cdots & a_{nn}(t)
\end{pmatrix}, \quad 
\mathbf{f}(t) = \begin{pmatrix} f_1(t) \\ f_2(t) \\ \vdots \\ f_n(t) \end{pmatrix} $$
则一阶线性微分方程组可写为：
$$ \frac{d\mathbf{x}}{dt} = A(t) \mathbf{x} + \mathbf{f}(t) $$
若 $\mathbf{f}(t) = \mathbf{0}$，则齐次方程为 $\mathbf{x}' = A(t) \mathbf{x}$。

##### 2.2 高阶方程化为方程组
单个 $n$ 阶微分方程 $y^{(n)} + p_{n-1}(t) y^{(n-1)} + \cdots + p_0(t) y = f(t)$ 可以通过引入新变量化为 $n$ 维一阶方程组。令 $x_1 = y, x_2 = y', \dots, x_n = y^{(n-1)}$，则：
$$ \begin{cases}
x_1' = x_2 \\
x_2' = x_3 \\
\vdots \\
x_{n-1}' = x_n \\
x_n' = -p_0 x_1 - p_1 x_2 - \cdots - p_{n-1} x_n + f(t)
\end{cases} $$
这是线性方程组。

#### 三、解的结构

对于一阶线性齐次方程组 $\mathbf{x}' = A(t) \mathbf{x}$，其解具有线性空间结构。

##### 3.1 齐次方程组解的性质
- 若 $\mathbf{x}_1(t), \mathbf{x}_2(t)$ 是解，则任意线性组合 $C_1 \mathbf{x}_1 + C_2 \mathbf{x}_2$ 也是解。
- 存在 $n$ 个线性无关的解，它们构成一个**基本解组**。所有解可表示为这 $n$ 个解的线性组合（通解）。
- 线性无关性可由**朗斯基行列式** $W(t) = \det[ \mathbf{x}_1(t) \ \mathbf{x}_2(t) \ \cdots \ \mathbf{x}_n(t)]$ 判断：若在某点 $t_0$ 处 $W(t_0) \neq 0$，则解组线性无关。

##### 3.2 非齐次方程组解的结构
设 $\mathbf{x}_p(t)$ 是非齐次方程的一个特解，$\mathbf{x}_h(t)$ 是对应齐次方程的通解，则非齐次方程的通解为：
$$ \mathbf{x}(t) = \mathbf{x}_h(t) + \mathbf{x}_p(t) $$

##### 3.3 基解矩阵
若 $\Phi(t)$ 是一个 $n \times n$ 矩阵，其每一列都是齐次方程组的线性无关解，则 $\Phi(t)$ 称为**基解矩阵**。齐次方程组的通解可写为 $\mathbf{x}(t) = \Phi(t) \mathbf{c}$，其中 $\mathbf{c}$ 是常数向量。基解矩阵满足 $\Phi'(t) = A(t) \Phi(t)$。

##### 3.4 刘维尔公式
朗斯基行列式满足 $W(t) = W(t_0) \exp\left( \int_{t_0}^t \operatorname{tr} A(s) ds \right)$，其中 $\operatorname{tr} A$ 是矩阵的迹（对角线元素之和）。

#### 四、常系数线性微分方程组

当 $A$ 是常数矩阵时，方程为 $\mathbf{x}' = A \mathbf{x} + \mathbf{f}(t)$。先讨论齐次情形 $\mathbf{x}' = A \mathbf{x}$。

##### 4.1 特征值与特征向量法
设解形式为 $\mathbf{x} = \mathbf{v} e^{\lambda t}$，其中 $\lambda$ 是常数，$\mathbf{v}$ 是常向量。代入得：
$$ \lambda \mathbf{v} e^{\lambda t} = A \mathbf{v} e^{\lambda t} \quad \Rightarrow \quad (A - \lambda I)\mathbf{v} = \mathbf{0} $$
因此 $\lambda$ 是 $A$ 的特征值，$\mathbf{v}$ 是对应的特征向量。

###### 4.1.1 特征值互异
若 $A$ 有 $n$ 个互异的特征值 $\lambda_1, \dots, \lambda_n$，对应特征向量 $\mathbf{v}_1, \dots, \mathbf{v}_n$，则齐次方程的通解为：
$$ \mathbf{x}(t) = C_1 \mathbf{v}_1 e^{\lambda_1 t} + C_2 \mathbf{v}_2 e^{\lambda_2 t} + \cdots + C_n \mathbf{v}_n e^{\lambda_n t} $$

###### 4.1.2 复特征值
若 $\lambda = \alpha + i\beta$ 是复特征值，则其实部、虚部对应的解可由复特征向量构造实解。设 $\mathbf{v} = \mathbf{a} + i\mathbf{b}$ 是对应特征向量，则两个实解为：
$$ \mathbf{x}_1(t) = e^{\alpha t}(\mathbf{a} \cos \beta t - \mathbf{b} \sin \beta t),\quad \mathbf{x}_2(t) = e^{\alpha t}(\mathbf{a} \sin \beta t + \mathbf{b} \cos \beta t) $$

###### 4.1.3 重特征值
当特征值有重根时，需要寻找广义特征向量。设 $\lambda$ 是 $k$ 重特征值，则解形式为：
$$ \mathbf{x}(t) = e^{\lambda t} \left( \mathbf{v}_0 + \mathbf{v}_1 t + \cdots + \mathbf{v}_{k-1} t^{k-1} \right) $$
其中 $\mathbf{v}_0, \mathbf{v}_1, \dots, \mathbf{v}_{k-1}$ 满足：
$$ (A - \lambda I) \mathbf{v}_0 = \mathbf{0}, \quad (A - \lambda I) \mathbf{v}_1 = \mathbf{v}_0, \quad \dots, \quad (A - \lambda I) \mathbf{v}_{k-1} = \mathbf{v}_{k-2} $$
这些向量构成循环（Jordan 链）。

##### 4.2 非齐次常系数方程组：待定系数法
对于非齐次项 $\mathbf{f}(t)$ 为指数函数、多项式、三角函数及其乘积的形式，可仿照标量情形设定特解形式。例如：
- 若 $\mathbf{f}(t) = e^{\lambda t} \mathbf{p}(t)$，其中 $\mathbf{p}(t)$ 是多项式向量，则特解可设为 $\mathbf{x}_p = t^s e^{\lambda t} \mathbf{q}(t)$，其中 $s$ 是 $\lambda$ 作为特征值的重数（若无则为0），$\mathbf{q}(t)$ 是与 $\mathbf{p}(t)$ 同次的多项式系数向量。
- 也可使用常数变易法（基解矩阵法）：若已知齐次方程基解矩阵 $\Phi(t)$，则特解为 $\mathbf{x}_p(t) = \Phi(t) \int \Phi^{-1}(t) \mathbf{f}(t) dt$。

#### 五、应用示例

##### 例1：解方程组
$$ \begin{cases}
x' = 2x + y \\
y' = 3x + 4y
\end{cases} $$
解：矩阵 $A = \begin{pmatrix} 2 & 1 \\ 3 & 4 \end{pmatrix}$。特征方程 $\det(A-\lambda I) = (2-\lambda)(4-\lambda) - 3 = \lambda^2 - 6\lambda +5 = 0$，特征值 $\lambda_1=1, \lambda_2=5$。
- 对 $\lambda=1$：$(A-I)\mathbf{v}=0$ ⇒ $\begin{pmatrix}1&1\\3&3\end{pmatrix}\mathbf{v}=0$，取 $\mathbf{v}_1=(1,-1)^T$。
- 对 $\lambda=5$：$(A-5I)\mathbf{v}=0$ ⇒ $\begin{pmatrix}-3&1\\3&-1\end{pmatrix}\mathbf{v}=0$，取 $\mathbf{v}_2=(1,3)^T$。
通解：$\begin{pmatrix}x\\y\end{pmatrix} = C_1 \begin{pmatrix}1\\-1\end{pmatrix} e^{t} + C_2 \begin{pmatrix}1\\3\end{pmatrix} e^{5t}$。

##### 例2：解含重特征值的方程组
$$ \mathbf{x}' = \begin{pmatrix} 1 & 1 \\ 0 & 1 \end{pmatrix} \mathbf{x} $$
特征值 $\lambda=1$（二重）。特征向量 $(A-I)\mathbf{v}=0$ ⇒ $\begin{pmatrix}0&1\\0&0\end{pmatrix}\mathbf{v}=0$，得 $\mathbf{v}=(1,0)^T$。需找广义特征向量：解 $(A-I)\mathbf{w} = \mathbf{v}$ ⇒ $\begin{pmatrix}0&1\\0&0\end{pmatrix}\mathbf{w} = \begin{pmatrix}1\\0\end{pmatrix}$，取 $\mathbf{w}=(0,1)^T$。通解：
$$ \mathbf{x}(t) = e^{t} \left[ C_1 \begin{pmatrix}1\\0\end{pmatrix} + C_2 \left( \begin{pmatrix}0\\1\end{pmatrix} + t \begin{pmatrix}1\\0\end{pmatrix} \right) \right] $$

#### 六、数值解法简介（与 5.5 部分重叠）

对于无法解析求解的微分方程组，可使用数值方法（如欧拉法、龙格-库塔法）。在“5.5 数值解法初步”中会有详细介绍，此处仅提概念。

#### 七、小结

微分方程组是处理多变量动态系统的数学工具。你需要掌握：
1. 微分方程组的基本概念（维数、线性、矩阵形式）。
2. 线性齐次方程组解的结构（线性空间、基本解组、朗斯基行列式）。
3. 常系数线性齐次方程组的解法：特征值与特征向量；重根时广义特征向量的处理。
4. 常系数非齐次方程组的特解求法（待定系数法或常数变易法）。
5. 高阶方程与一阶方程组的互化。

### 5.5 数值解法初步（欧拉法、改进欧拉法）<a id = "5.5"></a>

在实际应用中，大多数微分方程无法求出解析解，或者解析解形式复杂难以使用。此时需要借助数值方法，在离散点上近似求解。本节介绍常微分方程初值问题的基本数值解法：欧拉法（Euler‘s method）和改进欧拉法（Heun’s method，又称预估-校正法）。这些方法是理解更高级数值算法的基础。

#### 一、初值问题与基本思想

##### 1.1 初值问题
一阶常微分方程初值问题的一般形式为：
$$ \begin{cases}
y' = f(x, y) \\ 
y(x_0) = y_0
\end{cases} $$
我们希望在区间 $[x_0, X]$ 上求出 $y(x)$ 的近似值。

##### 1.2 离散化
将区间 $[x_0, X]$ 等分为 $n$ 个子区间，步长 $h = \frac{X - x_0}{n}$，节点 $x_i = x_0 + i h$（$i = 0, 1, \dots, n$）。数值方法的目标是计算 $y(x_i)$ 的近似值 $y_i$。

##### 1.3 基本思路
利用微分方程 $y' = f(x, y)$ 的几何意义：在点 $(x_i, y_i)$ 处的切线斜率为 $f(x_i, y_i)$。通过差商近似导数，建立递推公式。

#### 二、欧拉法

##### 2.1 公式推导
在 $x_i$ 处，由导数定义：
$$ y'(x_i) \approx \frac{y(x_{i+1}) - y(x_i)}{h} $$
又 $y'(x_i) = f(x_i, y(x_i))$，从而：
$$ y(x_{i+1}) \approx y(x_i) + h f(x_i, y(x_i)) $$
用近似值 $y_i$ 替换 $y(x_i)$，得到欧拉递推公式：
$$ y_{i+1} = y_i + h f(x_i, y_i), \quad i = 0, 1, \dots, n-1 $$

##### 2.2 几何意义
欧拉法是用折线近似积分曲线：从起点 $(x_0, y_0)$ 出发，以斜率 $f(x_0, y_0)$ 走一步到达 $(x_1, y_1)$，再以新斜率继续，形成一条折线。

##### 2.3 局部截断误差与整体误差
- **局部截断误差**：假设 $y_i = y(x_i)$ 精确，则欧拉法一步的误差为 $O(h^2)$。
- **整体截断误差**：累积 $n = (X-x_0)/h$ 步后，误差为 $O(h)$。因此欧拉法是一阶精度。

##### 2.4 示例
用欧拉法解 $y' = y - 2x / y$，$y(0)=1$，步长 $h=0.1$，求 $y(0.3)$ 的近似值。
解：$f(x,y) = y - 2x / y$。
- $x_0=0, y_0=1$，$k_0 = f(0,1)=1$，$y_1 = 1 + 0.1×1 = 1.1$。
- $x_1=0.1$，$k_1 = f(0.1,1.1)=1.1 - 0.2/1.1 ≈ 1.1 - 0.1818 = 0.9182$，$y_2 = 1.1 + 0.1×0.9182 = 1.19182$。
- $x_2=0.2$，$k_2 = f(0.2,1.19182)=1.19182 - 0.4/1.19182 ≈ 1.19182 - 0.3357 = 0.85612$，$y_3 = 1.19182 + 0.1×0.85612 = 1.27743$。
所以 $y(0.3) ≈ 1.27743$。

#### 三、改进欧拉法（预估-校正法）

欧拉法精度低，改进欧拉法通过“预估-校正”提高精度。它利用梯形公式近似积分，得到二阶精度。

##### 3.1 梯形公式
对 $y' = f(x,y)$ 在 $[x_i, x_{i+1}]$ 上积分：
$$ y(x_{i+1}) = y(x_i) + \int_{x_i}^{x_{i+1}} f(x, y(x)) dx $$
用梯形公式近似积分：
$$ \int_{x_i}^{x_{i+1}} f(x, y(x)) dx \approx \frac{h}{2} \left[ f(x_i, y_i) + f(x_{i+1}, y(x_{i+1})) \right] $$
得到：
$$ y_{i+1} = y_i + \frac{h}{2} \left[ f(x_i, y_i) + f(x_{i+1}, y_{i+1}) \right] $$
这是隐式方程，需迭代求解。

##### 3.2 预估-校正过程
为了避免求解隐式方程，先用欧拉法预估一个值 $\bar{y}_{i+1}$，再用梯形公式校正：
- **预估**：$\bar{y}_{i+1} = y_i + h f(x_i, y_i)$
- **校正**：$y_{i+1} = y_i + \frac{h}{2} \left[ f(x_i, y_i) + f(x_{i+1}, \bar{y}_{i+1}) \right]$

##### 3.3 局部截断误差
改进欧拉法的局部截断误差为 $O(h^3)$，整体误差为 $O(h^2)$，是二阶方法。

##### 3.4 示例
同上题，用改进欧拉法计算 $y(0.3)$，$h=0.1$。
- $x_0=0, y_0=1$，$f_0 = f(0,1)=1$。
- 预估：$\bar{y}_1 = 1 + 0.1×1 = 1.1$。
- 校正：$f_1^{预} = f(0.1,1.1) = 1.1 - 0.2/1.1 = 0.91818$，$y_1 = 1 + 0.05×(1 + 0.91818) = 1 + 0.05×1.91818 = 1.095909$。
- $x_1=0.1$，$f_1 = f(0.1,1.095909)=1.095909 - 0.2/1.095909 ≈ 1.095909 - 0.1825 = 0.913409$。
- 预估：$\bar{y}_2 = 1.095909 + 0.1×0.913409 = 1.187250$。
- 校正：$f_2^{预}=f(0.2,1.187250)=1.187250 - 0.4/1.187250 ≈ 1.187250 - 0.3369 = 0.85035$，$y_2 = 1.095909 + 0.05×(0.913409+0.85035) = 1.095909 + 0.05×1.763759 = 1.095909 + 0.088188 = 1.184097$。
- $x_2=0.2$，$f_2 = f(0.2,1.184097)=1.184097 - 0.4/1.184097 ≈ 1.184097 - 0.3378 = 0.84630$。
- 预估：$\bar{y}_3 = 1.184097 + 0.1×0.84630 = 1.268727$。
- 校正：$f_3^{预}=f(0.3,1.268727)=1.268727 - 0.6/1.268727 ≈ 1.268727 - 0.4730 = 0.79573$，$y_3 = 1.184097 + 0.05×(0.84630+0.79573) = 1.184097 + 0.05×1.64203 = 1.184097 + 0.08210 = 1.266197$。
所以 $y(0.3) ≈ 1.26620$（精确解约为 $1.266$）。

#### 四、数值方法的稳定性与步长选择

- **稳定性**：欧拉法对某些方程（如刚性方程）不稳定，步长需足够小。
- **步长选择**：步长越小精度越高，但计算量增大且可能累积舍入误差。实际中常采用变步长方法（如Runge-Kutta-Fehlberg）自动调整步长。

#### 五、与其他数值方法的联系

- 欧拉法和改进欧拉法是龙格-库塔法（Runge-Kutta）的特例。标准四阶龙格-库塔法（RK4）是应用最广泛的单步法，精度高。
- 多步法（如Adams-Bashforth）利用前面多点的信息提高效率。

#### 六、小结

数值解法是求解微分方程近似解的重要工具。你需要掌握：
1. 欧拉法的公式、几何意义、误差阶（一阶）。
2. 改进欧拉法的预估-校正过程、误差阶（二阶）。
3. 能够手工计算简单问题的几步近似。
4. 了解步长选择与稳定性的基本概念。
